DATA STRUCTURES & ALGORITHMS LAB

数据结构与算法可视化实验室

通过纯 SVG 与原生 JavaScript 逐步可视化八大类经典算法：排序、图遍历、最短路径、动态规划、贪心、回溯、并查集以及线段树与树状数组。每个模块均支持交互控制与实时统计，帮助直观理解算法的执行过程与时间复杂度。

8 Modules SVG + Vanilla JS Zero Dependencies Single File
01SORTING ALGORITHMS

排序算法全家桶

通过柱状图逐步展示冒泡、选择、插入、归并、快速、堆排序的比较与交换过程，实时统计比较次数、交换次数与时间复杂度。

排序过程可视化
02GRAPH TRAVERSAL

图遍历 - BFS 与 DFS

在随机生成的无向图上展示广度优先搜索（BFS）逐层扩展与深度优先搜索（DFS）深入回溯的节点探索顺序，动态显示已访问节点与前沿队列/栈。

图遍历可视化
03SHORTEST PATH

最短路径算法

可视化 Dijkstra、Bellman-Ford 与 A* 算法在加权图上的边松弛过程，动态更新各节点距离估计，最终高亮源点到目标的最短路径。

最短路径可视化
04DYNAMIC PROGRAMMING

动态规划

逐格填充 DP 表格，可视化 0/1 背包、最长公共子序列、编辑距离与找零问题的状态转移过程，并回溯最优解。

DP 表格填充
05GREEDY ALGORITHMS

贪心算法

展示 Huffman 编码、活动选择、分数背包与 Kruskal 最小生成树在每一步的贪心选择，逐步构建最优或近似最优解。

贪心选择可视化
06BACKTRACKING

回溯与分支限界

通过决策树与棋盘可视化 N 皇后、数独、全排列与子集和问题的搜索过程，展示分支探索、剪枝与回溯到死胡同的回退。

回溯搜索可视化
07DISJOINT SET UNION

并查集 Union-Find

可视化并查集数据结构的合并与查找操作，对比路径压缩与按秩合并对树深度的影响，动态统计集合数量与最大深度。

并查集森林可视化
08SEGMENT & FENWICK TREE

线段树与树状数组

可视化线段树与树状数组（Fenwick Tree）的建树、区间查询与单点更新过程，对比两种数据结构在范围统计上的差异。
