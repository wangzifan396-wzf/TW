MODULE 02

量子核 (Quantum Kernel)

经典数据经量子特征映射 φ(x)=U(x)|0⟩ 投射到高维 Hilbert 空间。核矩阵 K[i,j]=|⟨φ(x_i)|φ(x_j)⟩|² 捕捉量子相似度。点击画布添加数据点，观察核矩阵热图更新。

quantum-kernel.svg
类 A 类 B 核值高(相似) 核值低(相异)

量子核方法

特征映射 U(x)=Ry(x) 将标量 x 编码为量子态 cos(x/2)|0⟩+sin(x/2)|1⟩。核值 K=cos²((x_i-x_j)/2)，x 越接近核值越接近 1。量子核可能提供经典难计算的亲和度。

QAOA 量子近似优化

量子近似优化算法求解 MaxCut 组合问题。p 层交替施加代价算子 e^{-iγH_C} 与混合算子 e^{-iβH_M}。调整层数 p 与参数，观察割值与最优解的逼近程度。

qaoa-maxcut.svg
集合 A 集合 B 被切割边 未切割边

MaxCut 与 QAOA

MaxCut 将图顶点分为两组使跨组边数最大。QAOA 用 p 层参数 (γ,β) 演化，测量得到候选解。p 越大近似越好，p→∞ 时趋于最优。

MODULE 05

量子感知机 (Quantum Perceptron)

将经典权重编码为量子旋转角，输入经量子态叠加后通过量子激活测量输出。对比经典符号激活与量子概率激活的差异。调整权重观察决策边界。

quantum-perceptron.svg
经典激活 量子激活 输入 权重

量子 vs 经典感知机

经典感知机 y=sign(w·x)；量子感知机将权重编码为 Ry(θ_w)，输入叠加后测量 |1⟩ 概率作为激活。量子激活是平滑概率函数，提供更丰富的梯度信息。

MODULE 06

数据编码 (Data Encoding)

将经典数据编码进量子态是量子机器学习的关键步骤。振幅编码将数据归一化为态振幅，角度编码将每维特征映射为旋转角。切换编码方式观察量子态表示。

data-encoding.svg
正振幅 负振幅 概率 |ψ|²

编码方式对比

振幅编码：N 维数据需 log₂N 量子比特，压缩比高但电路深。角度编码：每维一个量子比特，电路浅但比特数多。两者各有取舍。

MODULE 07

混合量子经典训练

参数化量子电路与经典优化器协同训练。参数移位法则 ∂f/∂θ=[f(θ+π/2)-f(θ-π/2)]/2 在量子设备上精确求梯度。播放动画观察损失下降与梯度更新。

hybrid-training.svg

参数移位梯度

量子电路的期望值 f(θ)=⟨ψ(θ)|O|ψ(θ)⟩ 对参数 θ 的梯度可用两次额外电路执行精确求得：∂f/∂θ=½[f(θ+π/2)-f(θ-π/2)]，无需自动微分。

MODULE 08

QNN vs ANN 对比

量子神经网络与经典神经网络在架构、参数、表达能力上的对比。QNN 以量子门参数为权重，测量输出概率；ANN 以矩阵权重与非线性激活堆叠。切换视图观察差异。

qnn-vs-ann.svg
QNN ANN 可训练参数

架构对比

QNN 参数集中于变分门旋转角，层数增加带来指数级希尔伯特空间探索；ANN 靠权重矩阵与 ReLU 等非线性堆叠。QNN 表达能力可能与指数级经典网络等价。
