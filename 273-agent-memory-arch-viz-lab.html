Agent记忆架构可视化实验室

记忆系统全景

Agent记忆借鉴认知科学,分为工作记忆(短期上下文)、情景记忆(经历事件)、语义记忆(知识图谱)三层,各有不同容量、持久性与检索方式。点击各层高亮。

点击按钮分层高亮,查看各层记忆的容量与职责

工作记忆:滑动窗口上下文管理

工作记忆是Agent的"意识焦点",用有限容量的滑动窗口管理近期上下文,配合注意力机制对近期token加权。点击切换窗口大小观察滑动与注意力衰减。

点击按钮切换窗口大小,观察token滑动与注意力分布

情景记忆:经历存储与回放

情景记忆按时间线存储Agent的具体经历事件(时间戳+上下文+动作+结果),支持时序回放、遗忘衰减与压缩归档。点击按钮模拟不同操作。

点击按钮:记录新事件 / 回放历史 / 遗忘衰减 / 压缩归档

语义记忆:知识图谱

语义记忆以知识图谱形式存储实体、关系与属性,支持图遍历检索与多跳推理。点击按钮高亮实体、关系、推理路径与查询结果。

点击按钮查看实体节点、关系边、推理路径与图查询

记忆巩固:睡眠期记忆整合

借鉴大脑睡眠巩固机制,Agent在空闲期将短期记忆经重要性过滤、稀疏化、聚类后转移至长期库,模拟海马体→新皮层整合。点击切换睡眠阶段。

点击按钮切换睡眠阶段,观察短期→长期记忆转移

检索增强记忆 (RAG)

RAG通过向量检索将外部记忆按需注入上下文:查询→检索→相似度匹配→上下文注入→生成,让Agent回答有据可依。点击按钮逐步高亮流水线。

点击按钮逐步查看RAG五步流水线

长上下文窗口 vs 外部记忆

长上下文窗口把信息全塞入模型,简单但贵且易注意力稀释;外部记忆按需检索,便宜精准但需维护索引。点击对比两种范式的权衡。

点击按钮对比长上下文窗口与外部记忆的权衡
