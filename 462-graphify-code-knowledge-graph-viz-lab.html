Graphify 是 YC S26 孵化项目，通过将代码库、文档、PDF、图片、视频等转换为统一的知识图谱，支持 Claude Code、Cursor、Codex、Gemini 等 26+ AI 编程助手。核心功能包括代码知识图谱构建、节点路径查询、增量索引和 GitHub Action 集成，一行命令即可安装使用。
