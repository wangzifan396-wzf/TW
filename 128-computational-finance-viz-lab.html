MODULE 01

期权定价 (Black-Scholes)

Black-Scholes 闭式公式与蒙特卡洛模拟对比。调整标的价格 S、行权价 K、波动率 σ、期限 T、无风险利率 r，观察欧式看涨/看跌期权价格与 Greeks 变化。

black-scholes.svg
看涨期权 Call 看跌期权 Put 蒙特卡洛样本 内在价值

Black-Scholes 公式

看涨期权 C = S·N(d₁) − K·e^(−rT)·N(d₂)，其中 d₁ = [ln(S/K) + (r + σ²/2)·T] / (σ√T), d₂ = d₁ − σ√T。N(·) 为标准正态累积分布。蒙特卡洛通过模拟到期价格 S_T=S·e^((r−σ²/2)T+σ√T·Z) 取均值贴现。

随机游走 (几何布朗运动)

gbm-paths.svg
模拟路径 均值路径 E[S_t] ±1σ 带

GBM 离散化

S_(t+Δt) = S_t·exp((μ − σ²/2)·Δt + σ·√Δt·Z)，Z~N(0,1)。E[S_T]=S₀·e^(μT)，Var[ln S_T]=σ²T。到期价格服从对数正态分布。

MODULE 03

投资组合 (Markowitz 有效前沿)

三资产 Markowitz 均值-方差模型。有效前沿为给定预期收益下方差最小的组合集合。拖动权重滑块在风险-收益空间中移动，观察组合相对前沿的位置。

efficient-frontier.svg
有效前沿 当前组合 最小方差 单项资产

均值-方差优化

组合收益 μ_p=wᵀμ，方差 σ_p²=wᵀΣw。有效前沿由 min σ_p² s.t. wᵀμ=μ_p, wᵀ1=1 求得。上半支为有效集，下半支（同风险更低收益）被淘汰。

MODULE 04

风险度量 (VaR / ES / CVaR)

在险价值 VaR 与期望损失 ES(CVaR) 衡量尾部风险。VaR 是给定置信水平的分位点损失；ES 是超出 VaR 部分的条件期望，满足子可加性，是更稳健的一致风险度量。

risk-measures.svg
损益分布 VaR 分位 ES 尾部 蒙特卡洛样本

VaR 与 ES 定义

VaR_α = inf{x: P(L≤x)≥α}，即损失分布的 α 分位点。ES_α = E[L | L≥VaR_α]，是超越 VaR 的平均损失。ES 满足一致性公理（次可加、单调、正齐次、平移不变），VaR 不满足次可加性。

MODULE 05

利率模型 (Vasicek / CIR)

短期利率的均值回复模型。Vasicek: dr = a(b−r)dt + σdW；CIR: dr = a(b−r)dt + σ√r dW。调整回复速度 a、长期均值 b、波动率 σ，观察利率路径与均值回复行为。

rate-models.svg
Vasicek 路径 CIR 路径 长期均值 b

均值回复机制

a(b−r) 项使利率向长期均值 b 回复，速度由 a 控制。Vasicek 允许利率为负；CIR 的 √r 项使波动随利率升高而增大，且利率趋于非负。两者均可写出债券价格的仿射期限结构解。

MODULE 07

因子模型 (CAPM / Fama-French)

资本资产定价模型 CAPM: E[R] = R_f + β·(E[R_m]−R_f)。Fama-French 三因子加入规模 SMB 与价值 HML。调整 β 与因子载荷，观察收益分解与证券特征线。

factor-model.svg
资产收益 vs 市场 SCL 回归线 (β) CAPM 预测 α 异常收益

CAPM 与三因子

CAPM 仅用市场因子解释收益，β 衡量系统性风险。SCL 回归 R_i − R_f = α + β(R_m − R_f) + ε。Fama-French 扩展为 R_i − R_f = α + β_m·MKT + β_s·SMB + β_v·HML + ε，捕捉规模与价值溢价。

MODULE 08

信用风险 (Merton 结构模型)

Merton 将股权视为公司资产的看涨期权：E = max(V_T − D, 0)。违约发生于到期资产价值 V_T 低于债务面值 D。调整资产波动率与杠杆，观察违约概率与违约距离的变化。

merton-model.svg
资产价值分布 违约区域 V<D 债务面值 D 股权 E=max(V−D,0)

Merton 结构模型

假设公司资产 V_T 服从对数正态，违约概率 PD = P(V_T < D) = N(−d₂)，其中违约距离 DD = [ln(V₀/D) + (μ − σ²/2)T] / (σ√T)。股权可由 Black-Scholes 看涨公式定价，信用利差随 PD 与杠杆上升。
