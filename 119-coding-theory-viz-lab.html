MODULE 01

Hamming 码 — 校验位与单错纠正

Hamming(7,4) 码：4 个数据位 + 3 个校验位。校验矩阵 H 的列即所有非零 3 位向量。Syndrome = H·rᵀ 指向出错位置。点击任意位翻转，观察 SEC 纠正。

hamming-code.svg
数据位 d 校验位 p 纠正后 错误位

Hamming(7,4) 编码与解码

点击下方码字任意位置翻转比特（注入错误）。Syndrome = H·rᵀ，若非零则其二进制值指向出错位编号，将该位翻转即完成单错纠正（SEC）。

H = [Pᵀ | I₃], syndrome s = H·rᵀ, 纠正 = flip bit s (if s≠0)

MODULE 02

LDPC 码 — Tanner 图与置信传播

低密度奇偶校验码：稀疏校验矩阵对应 Tanner 图（变量节点 + 校验节点）。Belief Propagation 在二分图上迭代传递软信息，逐步收敛到有效码字。

ldpc-tanner.svg
变量节点 VN 校验节点 CN 已满足校验 未满足校验

Belief Propagation 迭代解码

变量节点向校验节点发送信道似然，校验节点回传外信息。点击“迭代”执行一轮消息传递。当所有校验节点满足（变绿）时解码成功。稀疏性保证每次更新 O(n)。

MODULE 03

Polar 码 — 信道极化与 SC 解码

极化变换将 N 个相同信道分裂为极端信道：一部分趋于无噪（容量→1），另一部分趋于全噪（容量→0）。选取高容量信道承载信息位，低容量冻结。SC 解码逐位判决。

polar-code.svg
信息位 (free) 冻结位 (frozen) 极化容量→1 极化容量→0

极化变换与 Successive Cancellation

N=8 时的极化蝴蝶网络。上半为高容量信道（承载信息），下半为低容量信道（冻结为 0）。SC 解码从 u₀ 开始，利用已判决位逐个估计后续位，复杂度 O(N log N)。

(u₀⊕u₁, u₁) → 信道 → 极化: W⁻ (差) 与 W⁺ (好)

MODULE 04

Reed-Solomon — 多项式与擦除纠正

RS 码将数据视为 GF(2ᵐ) 上多项式的系数，传输其在若干点的求值。只要收到 k 个正确点即可插值还原多项式，纠正 2t 个符号错误或 t 个擦除。广泛用于 CD/DVD/QR 码。

reed-solomon.svg
正确点 擦除点 原多项式 插值恢复

多项式求值编码 + Lagrange 插值解码

k=4 个数据系数定义 3 次多项式，在 n=7 个点求值传输。点击任意点标记为擦除。只要剩余 ≥ k 个正确点，Lagrange 插值即可精确还原原多项式。

P(x)=d₀+d₁x+d₂x²+d₃x³, 编码 = {P(α₀),...,P(αₙ₋₁)}

MODULE 05

Turbo 码 — 并行级联与迭代解码

两个递归系统卷积码（RSC）通过交织器并行级联。BCJR 算法在后验概率上迭代交换外信息（extrinsic），软信息在两个 SISO 解码器间反复精炼，逼近 Shannon 极限。

turbo-code.svg
系统位 校验位 1 校验位 2 外信息收敛

并行级联卷积编码

编码器 1 直接处理数据流，编码器 2 处理交织后的数据流。交织器打散突发错误。解码端两个 BCJR 解码器交替工作，传递外信息 LLR。点击“迭代”观察外信息逐步收敛。

L_e(û) = L(û) - L_ch - L_apriori (外信息 = 后验 − 信道 − 先验)

MODULE 06

Shannon 极限 — 信道容量与编码增益

Shannon 信道编码定理：只要码率 R < C(信道容量)，就存在码使差错概率任意小。BSC 容量 C=1−H(p)，AWGN 容量 C=½log₂(1+SNR)。现代码（Turbo/LDPC/Polar）逼近此极限。

shannon-limit.svg
BSC 容量 C=1−H(p) AWGN 容量 Shannon 极限 现代码性能

信道容量曲线

左侧为 BSC 容量随错误率 p 变化，右侧为 AWGN 容量随 SNR 变化。Shannon 极限线上方可实现可靠传输。现代码（LDPC/Turbo/Polar）工作点距极限仅 0.5~1 dB（编码增益）。

C_BSC = 1 − H(p), C_AWGN = ½·log₂(1 + SNR) bits/symbol

MODULE 07

交织与打孔 — 码率匹配

交织（Interleaving）打散突发错误使其适合随机纠错码；打孔（Puncturing）选择性删除校验位以提升码率。二者结合实现灵活的码率匹配，是 5G/LTE 的关键技术。

interleaving.svg
数据位 校验位 突发错误 打孔删除

块交织 + 打孔

块交织：数据按行写入矩阵、按列读出，突发错误被分散到不同码字。打孔：按图案删除部分校验位以提升码率。切换模式观察突发错误的分散效果与码率变化。

R_punctured = k / (n − 删除数), 交织深度 = 行数

MODULE 08

5G 编码 — LDPC + Polar 组合方案

3GPP 5G NR 采用双码方案：数据信道（PDSCH/PUSCH）使用 LDPC 码（高效支持大块、低延迟、增量冗余 HARQ）；控制信道与广播（PDCCH/PBCH）使用 Polar 码（短码性能优、确定性构造）。

5g-coding.svg
LDPC (数据) Polar (控制) Turbo (4G 对比) Shannon 极限

5G 编码方案对比

数据信道选 LDPC：quasi-cyclic 结构支持并行解码，HARQ-IR 增量冗余高效。控制信道选 Polar：短码（≤1024）SC/SCL 解码性能优于 LDPC，且构造确定、时延可控。切换码长观察性能曲线差异。

5G NR: LDPC (data, 高吞吐) + Polar (control, 短码优) > 4G Turbo
