模块化AI Agent开发工具包 · 四大核心包 · Gondolin虚拟机 · 沙盒隔离
Pi 是模块化 AI Agent 开发工具包与编码助手，采用 Monorepo 架构管理四大核心包：pi-ai 提供统一多提供商 LLM API、pi-agent-core 提供 Agent 运行时、pi-tui 提供终端 UI 库、pi-coding-agent 提供编码 Agent CLI。内置 Gondolin 微虚拟机、Docker 与 OpenShell 三层沙盒隔离机制，保障代码执行安全，是构建生产级 AI Agent 应用的完整工具链。
