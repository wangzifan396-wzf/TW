AI Agent记忆架构可视化实验室

从工作记忆到长期记忆——把2026年AI Agent如何存储、检索和遗忘信息的记忆系统以可交互SVG呈现。

01

记忆类型分类

五种记忆类型：工作记忆（上下文窗口）、短期记忆（会话级）、长期记忆（持久化）、情景记忆（事件序列）、语义记忆（知识图谱）。切换类型查看特征。

02

工作记忆管理

上下文窗口管理：Token预算分配（系统提示/历史对话/当前查询/输出空间）、滑动窗口、摘要压缩。调整窗口大小观察Token分配。

03

长期记忆存储

长期记忆存储架构：向量数据库（语义检索）→ 知识图谱（关系推理）→ 文档存储（原始记录）。三种存储协同工作。

04

记忆编码与检索

记忆编码（Embedding生成）与检索（相似度搜索+重排序）的完整流程：事件输入 → 编码 → 索引 → 查询 → 检索 → 排序 → 返回。

05

记忆压缩与遗忘

记忆管理策略：摘要压缩（多轮对话→摘要）、聚类去重、时间衰减遗忘、重要性评分保留。时间轴展示记忆的保留/遗忘过程。

06

情景记忆回放

时间序列事件存储与回放：事件编码（时间+内容+情感）→ 时间线索引 → 回放检索 → 时序推理。时间轴+事件卡片展示情景记忆。

07

记忆一致性管理

记忆冲突解决：新信息 vs 旧记忆 → 冲突检测 → 更新策略（覆盖/合并/标记）→ 一致性校验。对比图展示冲突解决过程。
