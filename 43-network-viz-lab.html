计算机网络可视化实验室

通过 8 个交互式可视化模块，深入理解计算机网络核心协议与机制：TCP 连接管理、拥塞控制、HTTP 请求响应、DNS 解析链路、路由算法、CDN 边缘缓存、NAT 地址转换与 TLS 加密通信。全部基于纯 SVG + 原生 JS 实现，零外部依赖，单文件可运行。

8 Modules SVG + Vanilla JS Zero Dependencies Single File
01TRANSPORT · CONNECTION MANAGEMENT

TCP 三次握手与四次挥手

可视化 TCP 连接的建立（三次握手 SYN / SYN-ACK / ACK）与断开（四次挥手 FIN / ACK）。观察客户端与服务端的序列号、确认号随报文交互的变化，以及连接状态机的迁移过程。

连接时序图 Sequence Diagram
02TRANSPORT · CONGESTION CONTROL

TCP 拥塞控制

可视化拥塞窗口 cwnd 随时间的演化：慢启动阶段指数增长、拥塞避免阶段线性增长、快重传与快恢复在收到 3 个重复 ACK 时触发，超时则窗口骤降。可手动触发丢包事件观察窗口变化。

拥塞窗口曲线 cwnd over Time
03APPLICATION · HTTP

HTTP 请求响应

可视化一次完整 HTTP 请求的生命周期：DNS 解析 → TCP 建连 → TLS 握手 → 请求发送 → 响应返回。可切换 GET/POST/PUT/DELETE 方法与 HTTP/1.1、HTTP/2、HTTP/3 协议版本，观察 RTT 与响应结构差异。

请求响应时序 Request/Response Cycle
04APPLICATION · DNS

DNS 解析

可视化域名解析的完整链路：浏览器缓存 → 操作系统缓存 → 本地递归解析器 → 根服务器 → TLD 服务器 → 权威服务器。可调节缓存命中率，切换递归与迭代查询模式，观察查询跳数与解析耗时。

DNS 解析层级 Resolution Hierarchy
05NETWORK · ROUTING

路由算法

可视化网络拓扑上的最短路径计算：Dijkstra（OSPF 链路状态）、Bellman-Ford（RIP 距离矢量）与 BGP 路径选择。可在图上增删链路、调节节点数量，观察路由表收敛与最短路径变化。

拓扑与最短路径 Topology & Shortest Path
06NETWORK · CDN

CDN 缓存与边缘

可视化 CDN 架构：源站 → 边缘节点 → 用户。观察缓存命中 / 未命中、内容回源与边缘节点地理就近选择。可调节边缘节点数量、新增内容、模拟请求并切换缓存开关，观察命中率与平均延迟。

CDN 边缘分发 Edge Distribution
07NETWORK · NAT

NAT 网络地址转换

可视化网络地址转换：私有 IP:端口 ↔ 公网 IP:端口的映射。观察出站报文经 NAT 路由器改写源地址、入站报文依据 NAT 表反向映射回内网主机。可调节内网主机数、切换 SNAT / DNAT 模式。

NAT 映射与报文流转 NAT Translation
08SECURITY · TLS

TLS 加密通信

可视化 TLS 握手与加密通信：ClientHello → ServerHello → 密钥交换 → Finished。可逐步执行握手步骤，切换 TLS 1.2（2-RTT）与 TLS 1.3（1-RTT / 0-RTT），观察密码套件协商与加密数据流。
