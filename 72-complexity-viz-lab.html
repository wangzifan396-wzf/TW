MODULE 03

时间复杂度增长对比

从 O(1) 到 O(n!) 的增长曲线。拖动滑块改变 n，观察不同复杂度函数的相对规模。当 n 超过某阈值，指数与阶乘函数将爆炸式增长。

time-complexity.svg

函数规模（n = 12）

常数与对数函数几乎水平；线性与 n log n 温和增长；多项式平稳上升；而 2ⁿ 与 n! 在 n 略大时即超出可计算范围。

MODULE 04

空间复杂度与内存使用

不同复杂性类的内存占用可视化。L ⊆ NL ⊆ PSPACE ⊆ EXPSPACE。调整输入规模，观察各层级空间需求的增长差异。

space-complexity.svg
L (logspace) NL PSPACE EXPSPACE

空间层次定理

对任意可构造函数 f，SPACE(f) ⊊ SPACE(f log f)。因此严格包含关系成立，更高空间允许判定更多语言。

MODULE 06

对角线化与停机问题

图灵对角线证明：构造机器 D，使其在第 i 个输入上的行为与第 i 台机器相反，导致 D 无法出现在枚举中，从而停机问题不可判定。自指悖论。

diagonalization.svg

对角线论证

假设存在能判定停机问题的图灵机 H。构造 D(x)：模拟 H(x,x)，若 H 说“停机”则 D 死循环，反之停机。问 D(D) 是否停机即导出矛盾——因此 H 不存在。

MODULE 07

Cook-Levin 定理

3SAT 是 NP 完全的。证明分两步：① SAT ∈ NP（赋值证书可多项式验证）；② 任意 NP 问题可多项式归约到 SAT——将非确定图灵机的计算表编码为合取范式。

cook-levin.svg

证明骨架

计算表是一张 T×T 的格子，每个单元格 cell[i,j] 表示时刻 i 在位置 j 的带符号/状态。用一组子句约束：合法初始格局、合法转移、接受格局可达。所有约束合取即为 SAT 实例。

MODULE 08

随机化复杂性类

BPP / RP / ZPP 与概率图灵机。RP 允许单侧错误，BPP 允许双侧错误，ZPP 零错误期望多项式时间。关系：ZPP = RP ∩ co-RP ⊆ BPP。

randomized.svg
接受 拒绝 错误路径 随机硬币
