生成模型可视化实验室

以纯 SVG 与原生 JavaScript 交互式呈现八类主流生成式模型的内部机理——从对抗博弈到扩散去噪，从重参数化到条件引导，让看不见的生成过程变得可观察、可调节。单文件、零依赖、下载即用。

8 Modules SVG + Vanilla JS Zero Dependencies Single File
01GENERATIVE ADVERSARIAL NETWORKS

GAN 对抗博弈

生成器将随机噪声映射为逼真样本，判别器区分真实与生成数据；二者在极小极大博弈中交替优化，损失曲线呈现对抗的拉锯与收敛。

对抗训练可视化
02VARIATIONAL AUTOENCODER

VAE 变分自编码器

编码器将输入压缩为分布的均值与方差，经重参数化技巧采样得到潜变量 z，解码器重建输入；KL 散度与重建误差共同构成 ELBO。

编码-采样-解码管线
03NORMALIZING FLOW

归一化流

一串可逆变换将简单的高斯分布逐步扭曲为复杂的目标分布，每一步的雅可比行列式可解析计算，从而精确最大化对数似然。

可逆变换链
04AUTOREGRESSIVE GENERATION

自回归生成

像 GPT 一样逐 token 生成：每一步依据已生成上下文预测下一 token 的概率分布，经温度与 top-k 采样后拼接到序列中。

逐 token 生成过程
05DIFFUSION MODELS

扩散模型对比

前向过程逐步加噪至纯高斯，反向过程学习去噪；DDPM 步数多、质量高，DDIM 少步加速，Score-based 以连续 SDE 统一框架。

前向加噪 / 反向去噪
06MODE COLLAPSE

模式崩塌

生成器为骗过判别器可能坍缩到少数模式，丢弃分布的多样性；本模块展示崩塌强度的演化、覆盖率下降与恢复机制。

真实分布 vs 生成分布
07FID / IS EVALUATION

FID/IS 评估

在 Inception 特征空间中计算真实与生成分布的 Fréchet 距离（FID），并以 Inception Score 衡量生成质量与多样性。

Inception 特征空间度量
08CONDITIONAL GENERATION

条件生成

类别标签作为条件注入生成过程，引导潜空间中样本落向对应簇；插值参数控制两类之间的平滑过渡。

类别引导与潜空间插值
