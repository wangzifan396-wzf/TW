SIGNAL PROCESSING · DSP

信号处理可视化实验室

8 个交互式模块，涵盖 FFT 蝶形运算、数字滤波器、采样定理、窗函数、小波变换、卷积、频谱分析与调制解调。所有可视化均使用纯 SVG 实时绘制，零外部依赖，单文件运行。

8 Modules SVG + Vanilla JS Zero Dependencies Single File
01RADIX-2 FFT · BUTTERFLY

FFT 蝶形运算

基-2 库利-图基（Cooley-Tukey）算法的蝶形结构可视化。逐步展示每一级蝶形运算与旋转因子 W_N^k，对比 N=8/16/32 点的运算规模。

蝶形信号流图 / Butterfly Diagram
02FIR / IIR DIGITAL FILTERS

FIR/IIR 滤波器

窗函数法设计 FIR 滤波器与双二阶（biquad）IIR 滤波器。观察冲激响应、幅频响应与衰减特性，比较线性相位与递归结构的差异。

滤波器响应 / Filter Response
03NYQUIST-SHANNON SAMPLING

采样定理

奈奎斯特-香农采样定理演示。调节采样率观察时域采样点与重建信号，当采样率低于 2 倍信号最高频率时出现频谱混叠。

采样与重建 / Sampling & Reconstruction
04WINDOW FUNCTIONS

窗函数

矩形窗、Hann、Hamming、Blackman 与 Kaiser 窗的时域形状与频域泄漏对比。观察主瓣宽度与旁瓣衰减的权衡。

窗函数频谱 / Window Spectrum
05WAVELET TRANSFORM

小波变换

Haar 与 DB4 小波多级分解。展示各级近似系数与细节系数，体现小波的多分辨率分析能力。

小波分解 / Wavelet Decomposition
06LINEAR & CIRCULAR CONVOLUTION

卷积

线性卷积与圆周卷积的翻转-平移-相加过程逐步演示。可单步执行或自动播放，观察输出序列的生成过程。

卷积过程 / Convolution Process
07SPECTRAL ANALYSIS · DFT

频谱分析

DFT 幅度谱与相位谱。输入正弦、方波或脉冲信号，叠加窗函数观察频谱泄漏与栅栏效应。

频谱可视化 / Spectrum
08AM / FM / PM MODULATION

调制解调

幅度调制（AM）、频率调制（FM）与相位调制（PM）。调节载波频率、调制指数与消息信号，观察时域波形与频谱搬移。

调制信号 / Modulated Signal
