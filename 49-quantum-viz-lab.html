01QUBIT · BLOCH SPHERE

量子比特

布洛赫球将单量子比特状态表示为单位球面上的一个点。|0⟩ 与 |1⟩ 位于两极，叠加态对应球面上的其他位置。状态矢量由 (x, y, z) 坐标确定。

布洛赫球可视化
02QUANTUM GATES · UNITARY

量子门

量子门是作用在量子比特上的酉变换。X/Y/Z 为泡利门，Hadamard 门创建叠加态，CNOT 门产生两比特纠缠。每个门对应一个酉矩阵。

门矩阵与态矢量变换
03SUPERPOSITION · AMPLITUDES

叠加态

n 个量子比特可同时处于 2^n 个基矢态的叠加中，每个基矢态具有概率振幅，振幅模平方即为测量概率。Hadamard 门可将 |0⟩^n 变换为均匀叠加。

多比特叠加概率分布
04ENTANGLEMENT · BELL STATE

量子纠缠

Bell 态是最简单的两比特最大纠缠态：( |00⟩ + |11⟩ ) / √2。通过 H 门 + CNOT 门生成。测量其中一个比特会瞬时决定另一个比特的结果，体现非局域关联。

Bell 对生成与关联测量
05MEASUREMENT · COLLAPSE

量子测量

测量使量子态坍缩到测量基的本征态。Z 基测量计算基，X 基测量对角基，Y 基测量圆偏振基。坍缩过程不可逆，概率由振幅模平方决定。

波函数坍缩动画
06GROVER · AMPLITUDE AMPLIFICATION

量子算法

Grover 搜索算法在无序数据库中实现平方根加速：约 √N 次迭代即可找到目标项，而经典算法需要 O(N)。通过 Oracle 标记 + 扩散算子放大目标振幅。

Grover 振幅放大
07ERROR CORRECTION · SYNDROME

量子纠错

3 比特位翻转码将 1 个逻辑量子比特编码为 3 个物理量子比特：|0⟩_L → |000⟩，|1⟩_L → |111⟩。通过奇偶校验子检测并纠正单比特翻转错误。

08QUANTUM ADVANTAGE · SCALING

量子优势

量子算法相较经典算法提供平方根至指数级加速。Grover 提供 O(√N) 加速，Shor 提供指数加速。随问题规模增大，量子优势愈发显著。
