ROBOTICS & CONTROL · MOTION PLANNING

机器人学与控制可视化实验室

交互式机器人学实验平台：从正逆运动学、SLAM、运动规划到 PID 控制、状态估计、轨迹优化、传感器融合与阻抗力控。每个模块均为纯 SVG 可视化与原生 JS 模拟，零外部依赖，单文件运行。

8 Modules SVG + Vanilla JS Zero Dependencies Single File
01FORWARD / INVERSE KINEMATICS

正逆运动学

二连杆机械臂：正运动学由关节角求末端位姿，逆运动学由末端目标解析求解关节角。拖拽末端目标点或调节关节角滑块，观察工作空间与关节构型变化。

二连杆机械臂运动学
02SLAM · LOCALIZATION & MAPPING

SLAM 同步定位与建图

机器人在未知环境中运动，里程计持续漂移，通过观测地标修正位姿并构建地图。粒子云表示位姿不确定性，对比真值轨迹、里程计轨迹与估计轨迹。

粒子滤波 SLAM
03MOTION PLANNING · RRT / A*

运动规划

在含障碍环境中规划无碰撞路径。RRT/RRT* 基于随机采样扩展搜索树，A* 基于栅格搜索最短路径。点击画布添加障碍，逐步观察树扩展与最终路径。

RRT / RRT* / A* 路径规划
04PID CONTROL · FEEDBACK

PID 控制

PID 控制器调节无人机高度：比例增益响应误差，积分消除稳态误差，微分抑制超调。调节 Kp/Ki/Kd 滑块并切换阶跃或正弦设定值，观察输出与误差随时间演化。

无人机高度 PID 控制
05STATE ESTIMATION · KALMAN FILTER

状态估计

卡尔曼滤波器融合带噪声的过程模型与测量，估计含速度的隐状态。调节过程噪声 Q 与测量噪声 R，开关预测与更新步骤，观察估计值、测量与真值及信念分布。

卡尔曼滤波器
06TRAJECTORY OPTIMIZATION · MIN-JERK

轨迹优化

在可拖拽航点间生成最小急动度（min-jerk）平滑轨迹，保证位置、速度、加速度连续。切换线性插值对比，观察速度与加速度曲线及沿轨迹运动的点。

最小急动度轨迹
07SENSOR FUSION · IMU + GPS

传感器融合

融合高频带偏置漂移的 IMU 与低频带噪声的 GPS：互补滤波器按频域加权，粒子滤波器用概率重采样。对比各传感器与融合估计相对真值的表现。

IMU + GPS 融合
08IMPEDANCE / FORCE CONTROL

力控与阻抗

阻抗控制使机械端点呈现期望质量-阻尼-刚度动力学，与环境接触时柔顺交互。调节刚度与阻尼，开关环境接触，观察位置跟踪与接触力关系。

阻抗控制与环境交互
