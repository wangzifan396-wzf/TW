LIF 脉冲神经元

Leaky Integrate-and-Fire 模型：膜电位 leaky 积分输入电流，超过阈值则发放脉冲并复位。SNN 的基本单元。调节电流与阈值观察发放模式。

lif-neuron.svg

τm dV/dt = −(V−Vrest) + R·I(t)，当 V ≥ Vth 发放并 V ← Vreset。τm 决定膜时间常数，R·I 为稳态目标电位。恒定电流足够大时呈周期发放，频率由 τm 与阈值决定。

MODULE 03

STDP 脉冲时序可塑性

Spike-Timing-Dependent Plasticity：突触权重改变量取决于前-后脉冲相对时序 Δt。Pre 先于 Post 触发 LTP（增强），反之触发 LTD（抑制）。拖动 Δt 观察权重变化。

stdp-curve.svg
LTP (Δt>0) LTD (Δt<0) 当前 Δt Pre / Post 脉冲

STDP 学习窗

Δw = A₊·exp(−Δt/τ₊) (Δt>0)　　Δw = −A₋·exp(Δt/τ₋) (Δt<0)Δt = t_post − t_pre。毫秒级时序不对称窗口使因果相关的 pre→post 强化，反向顺序弱化，实现局部无监督学习。

MODULE 05

神经编码策略

Rate Code 用发放率编码刺激强度；Temporal Code 用精确脉冲时序；Population Code 用群体向量编码。切换方案与刺激值，观察光栅图差异。

neural-coding.svg
脉冲 刺激强度 群体向量

编码说明

Rate Code：发放率随刺激单调增加，简单但慢。Temporal Code：脉冲相位锁定到刺激周期，精度高。Population Code：多个神经元钟形调谐曲线，群体向量解码方向等连续变量。

MODULE 08

SNN vs ANN 对比

脉冲神经网络 (SNN) 与传统人工神经网络 (ANN) 在能耗、延迟、精度、事件驱动性等维度的对比。切换视图观察雷达图与柱状图差异。

snn-vs-ann.svg
SNN ANN

对比维度

SNN 采用脉冲编码与事件驱动计算，在神经形态硬件上能耗可低至数个数量级，且支持低延迟实时推理；但训练困难、精度通常略低于 ANN。ANN 在 GPU 上成熟、精度高，但能耗与延迟较大。
