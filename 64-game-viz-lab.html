博弈论与机制设计可视化实验室

通过交互式 SVG 可视化探索博弈论与机制设计的核心概念:从纳什均衡、囚徒困境到拍卖机制、Shapley 值与 VCG 机制。八个模块覆盖纯策略与混合策略均衡、重复博弈中的合作演化、进化博弈的复制者动力学,以及激励相容的机制设计,全部基于纯 HTML/CSS/JS 与 SVG 实现。

8 Modules SVG + Vanilla JS Zero Dependencies Single File
01NASH EQUILIBRIUM

纳什均衡

2×2 支付矩阵与最优反应动力学。纯策略纳什均衡是双方互为最优反应的策略组合;混合策略均衡则令对手在策略间无差异。通过最优反应迭代可视化均衡的收敛过程。

支付矩阵与最优反应
02PRISONER'S DILEMMA

囚徒困境

经典的囚徒困境:合作(C)与背叛(D)。背叛是占优策略,但双方背叛劣于双方合作。在无限重复博弈中,合作可通过未来惩罚维持。可视化单轮选择与迭代博弈中的策略演化。

支付矩阵与迭代演化
03AUCTION MECHANISMS

拍卖机制

四种经典拍卖:英式(增价)、荷式(减价)、密封一价、维克里(密封二价)。不同机制下成交价与卖家收入各异,维克里拍卖中真实报价是占优策略。可视化报价过程与收入比较。

报价过程与收入
04REPEATED GAMES

重复博弈

无限重复囚徒困境中,策略如一报还一报(Tit-for-Tat)、冷酷触发(Grim Trigger)能维持合作。折现因子 δ 决定合作是否可被均衡支持。可视化逐轮行动与合作率演化。

策略对弈与合作演化
05EVOLUTIONARY GAME

进化博弈

复制者动力学描述群体中策略比例的演化:dx/dt = x(1-x)·Δ适应度。鹰鸽博弈存在混合进化稳定策略(ESS);协调博弈有两个纯均衡。可视化种群比例随时间的演化轨迹。

复制者动力学
06SHAPLEY VALUE

Shapley 值

Shapley 值将联盟价值按公平方式分配给参与者:对每个排列计算边际贡献并取平均。满足效率、对称性、哑元性与可加性四大公理。可视化所有排列的边际贡献与最终分配。

联盟价值分配
07ZERO-SUM GAMES

零和博弈

二人零和博弈中, minimax 定理保证:max_p min_q pᵀAq = min_q max_p pᵀAq = 博弈值。混合策略通过线性规划求解。可视化极小化极大解与博弈值。

极小化极大解
08MECHANISM DESIGN

机制设计

机制设计是博弈论的逆向工程:设计规则使自利参与者在占优策略中如实报告。VCG 机制分配给社会价值最高者,支付为他人施加的外部性。可视化分配、支付与激励相容性。

VCG 与激励相容
