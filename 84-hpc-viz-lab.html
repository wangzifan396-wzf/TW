04 / MapReduce

≣MapReduce 流水线

MapReduce 将大数据处理拆分为 Map（映射）、Shuffle（洗牌）、Reduce（归约）三阶段。本模块动画演示键值对在各阶段间的流动与重组。

05 / Amdahl

↗Amdahl 定律

Amdahl 定律揭示了并行计算的加速上限：即使无限增加处理器，串行部分仍制约整体加速比。本模块可视化加速比曲线与并行比例 p 的影响。

加速比公式：S = 1 / ((1-p) + p/N)，其中 p 为可并行比例，N 为处理器数。当 N→∞ 时，最大加速比 S_max = 1/(1-p)——串行部分 1-p 是加速比的不可逾越上限。

06 / Cache

▦Cache 优化

矩阵遍历的访问模式直接影响 Cache 命中率。本模块对比逐行遍历（空间局部性好）与逐列遍历（局部性差），并展示 Tiling/Blocking 分块如何提升复用。

已访问 当前 Cache Line Tile 块 Cache Miss
访问模式
矩阵大小 8×8
Tile 大小 4
CPU 按 Cache Line（通常 64B）加载内存。行主序遍历连续访问，命中率高；列遍历跨行跳跃，每次访问触发 Miss。Tiling 将矩阵分成小块，使每块完全驻留 Cache，大幅提升空间与时间局部性。
