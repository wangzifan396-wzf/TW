提示工程可视化实验室

通过交互式 SVG 可视化，直观理解 8 种核心提示工程技术的工作原理。调整参数、观察变化、深入理解每种技术的内部机制。

01 / FEW-SHOT PROMPTING

Few-Shot 提示

通过在提示中提供少量输入-输出示例，引导模型理解任务模式并生成更准确的响应。调整示例数量观察 token 开销与效果的变化。

02 / CHAIN-OF-THOUGHT

思维链 (Chain-of-Thought)

让模型逐步展示推理过程，而非直接给出答案。对比"直接回答"与"CoT 推理"两种模式，观察推理深度对准确率和延迟的影响。

03 / REACT PATTERN

ReAct 模式 (Reasoning + Acting)

结合推理 (Thought) 与行动 (Action)，模型可以调用外部工具获取观察 (Observation)，形成闭环决策循环，逐步逼近最终答案。

04 / SELF-CONSISTENCY

自一致性 (Self-Consistency)

对同一问题生成多条推理路径，通过投票选择最一致的答案。调整采样数和温度，观察答案分布与置信度的变化。

05 / TREE-OF-THOUGHT

思维树 (Tree-of-Thought)

将思维过程组织为树形结构，支持 BFS / DFS / Beam Search 等搜索策略。在中间步骤进行评估和剪枝，寻找最优推理路径。

06 / ROLE-PLAYING

角色扮演 (Role-Playing)

通过 System Prompt 定义模型的角色身份、能力、约束、语气和输出格式。切换不同角色模板，观察组件组合如何塑造模型行为。

07 / STRUCTURED OUTPUT

结构化输出 (Structured Output)

对比 JSON Schema、函数调用和 XML 标签三种结构化输出方式。观察 LLM 输出经过解析器转化为结构化数据的完整流程。

08 / PROMPT INJECTION DEFENSE

Prompt 注入防御

展示提示注入攻击的常见形式（直接注入、间接注入、越狱）及多层防御策略，包括输入过滤、内容消毒和角色边界锁定。
