MODULE 03

构建缓存与 Docker 层

Docker 镜像分层构建，未变更的层可被缓存复用；依赖缓存以 cache key 命中。切换 cache key 策略，观察命中与重建。

build-cache.svg
缓存命中 缓存未命中 依赖缓存 新构建层

缓存策略

cache key 由 lock 文件哈希、OS、分支等组成。key 匹配则整层复用（绿）；否则从该层起重新构建（红）。合理的层切分能最大化缓存复用。

MODULE 05

部署策略：蓝绿 / 金丝雀 / 滚动

蓝绿切换瞬时换组；金丝雀按比例放量灰度；滚动更新逐步替换。切换策略并调整金丝雀流量，观察实例与流量变化。

deployment.svg
旧版 v1 新版 v2 流量 异常

部署策略

蓝绿：两套环境并存，路由瞬时切换，回滚即切回。金丝雀：小比例流量验证，逐步放量，异常即回退。滚动：逐个替换实例，资源占用低但混合期长。

GitOps 与 ArgoCD 声明式

Git 作为 Source of Truth，ArgoCD 持续比对 Git 期望状态与集群实际状态，发现 Drift 即告警/自动同步。引入漂移观察自愈。

gitops.svg

MODULE 08

回滚机制与快速恢复

版本回退将生产拉回已知良好版本；Feature Flag 无需重新部署即可关停异常特性。两者配合实现快速恢复。
