Natural Language Processing · 可视化实验室

用交互式可视化理解自然语言处理的核心流程

从子词分词到 RAG 检索增强，8 个模块以可交互的方式呈现 NLP 中最关键的算法与数据流。每个模块都包含可视化、可调参数与实时统计。

8 个模块 零 依赖 SVG 矢量渲染 主色 #a78bfa violet 主题
MODULE 01

分词与编码

BPE / WordPiece 子词分词。将文本拆分为子词单元，通过合并规则逐步构建词表，缓解未登录词（OOV）问题。

MODULE 02

词嵌入

Word2Vec 将词语映射为稠密向量。Skip-gram 用中心词预测上下文，CBOW 用上下文预测中心词。近邻词在向量空间中距离更近。

MODULE 03

命名实体识别 (NER)

BIO 序列标注：B-X 标记实体首字，I-X 标记实体内部，O 为非实体。CRF 通过转移约束解码，SPAN 直接预测实体片段。

MODULE 04

依存句法分析

Shift-Reduce 移进归约解析器维护栈与缓冲区：SHIFT 移入词，LEFT-ARC / RIGHT-ARC 建立依存弧，最终生成依存树。
