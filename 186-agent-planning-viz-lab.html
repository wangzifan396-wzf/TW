AI Agent 规划与推理可视化实验室

从任务分解到反思修正——把 2026 年 AI Agent 如何规划、执行和自我修正复杂任务的核心机制以可交互 SVG 呈现。

01

任务分解策略

三种任务分解方法：自顶向下（目标→子目标→步骤）、自底向上（能力→动作→目标）、混合策略。点击执行观察分解过程。

02

Plan-and-Execute 架构

Planner（生成计划）→ Executor（逐步执行）→ Replanner（动态调整）的完整循环，展示计划执行与重规划过程。

03

ReAct 推理模式

Reason-Act-Observe 循环：推理（Thought）→ 行动（Action）→ 观察（Observation）→ 推理...每步以气泡显示推理内容。

04

层次化规划

三层规划：战略层（长期目标）→ 战术层（中期计划）→ 操作层（即时动作）。金字塔展示层级关系与数据流动。

05

反思与自我修正

Reflection Loop：执行 → 评估 → 反思 → 修正 → 重新执行。环形流程图标注每步的输入输出。

06

规划搜索算法

前向搜索 vs 逆向搜索 vs 双向搜索三种规划搜索策略，搜索树展示不同方向的扩展过程，高亮最优路径。

07

计划评估与选择

多计划生成 → 多维评估（可行性 / 效率 / 安全性 / 成本）→ 排序选择。雷达图展示候选计划的多维评分。
