MODULE 02

Cypher 查询语言

Neo4j 的声明式图查询语言。MATCH 匹配模式、WHERE 过滤、RETURN 投影、CREATE 写入。切换查询语句观察匹配结果。

cypher-query.svg
匹配节点 匹配关系 其他节点

Cypher 语法

Cypher 用 ASCII 艺术表达图模式：(n:Label) 表示节点，-[r:TYPE]-> 表示有向关系。MATCH 子句做模式匹配，WHERE 做谓词过滤。

MODULE 03

图遍历算法

BFS 广度优先、DFS 深度优先、最短路径（Dijkstra）。调节最大深度，播放动画观察访问顺序与剪枝效果。

traversal.svg
已访问 当前节点 前沿 Frontier 未访问

遍历说明

BFS 用队列，逐层扩展，适合最短跳数。DFS 用栈，深入到底再回溯，适合连通性与环检测。深度限制可控制遍历范围，类似 Cypher 的 depth 参数。

MODULE 04

在目标图中查找与模式图同构的子图。切换不同模式，观察匹配结果。子图同构是 NP-完全问题。

MODULE 05

索引策略

标签索引、属性索引、全文索引、组合索引。切换索引开关，观察全表扫描与索引查找的访问量差异。

MODULE 06

ACID 事务与锁机制

图数据库的事务隔离与锁。两个事务并发读写同一节点时，观察共享锁、排他锁与死锁。逐步执行观察隔离级别效果。

acid-transaction.svg
共享锁 S (读) 排他锁 X (写) 提交 等待

事务隔离

Neo4j 默认 Read Committed 隔离级别：读加短时共享锁，写加排他锁直至提交。两阶段锁（2PL）保证可串行化，但可能死锁，需检测与回滚。

MODULE 07

社区检测算法

Louvain 模块度、PageRank 中心性、Connected Components 连通分量。运行算法观察社区划分与节点重要性。

community-detection.svg
社区 A 社区 B 社区 C 社区 D

算法说明

Louvain 通过最大化模块度 Q 划分社区；PageRank 用随机游走迭代计算节点重要性；Connected Components 用并查集找连通块。均为图数据库 GDS 库核心算法。
