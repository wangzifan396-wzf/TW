阿波罗11号制导计算机源代码 · AGC汇编 · 早期航天软件工程的里程碑
Apollo-11 仓库汇集了阿波罗11号制导计算机(AGC)的原始源代码，包括指令舱 Comanche 和登月舱 Luminary 两大 rope 模块。代码以 AGC 汇编语言编写，运行于仅有 4KB RAM / 36KB ROM 的 16 位计算机上，实现了轨道计算、制导方程、导航滤波与登月着陆等关键算法，是人类登月任务的核心软件遗产。
