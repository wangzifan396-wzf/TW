CAUSAL INFERENCE · VISUAL LAB

因果推断可视化实验室

通过 8 个交互式 SVG 模块直观理解因果推断的核心概念：从因果图与 do-算子，到反事实、倾向得分匹配、工具变量、因果发现、双重差分，再到多种估计方法的对比。纯前端实现，零依赖，所有计算与渲染均在浏览器本地完成。

8 Modules SVG + Vanilla JS Zero Dependencies Single File
01DIRECTED ACYCLIC GRAPH

DAG 因果图

有向无环图（DAG）用节点表示变量、有向边表示因果关系。点击边可删除/恢复，点击节点可将其加入条件集。切换高亮模式可识别混杂因子、碰撞子、中介子，并追踪后门路径与 d-分离状态。

因果图编辑器
02DO-OPERATOR & INTERVENTION

do-算子与干预

观察分布 P(Y|X) 与干预分布 P(Y|do(X)) 的本质区别：do-算子会"切断"指向 X 的所有入边，从而阻断混杂路径。拖动滑块改变干预值，对比观测估计（有偏）与干预估计（无偏）的分布差异。

观察 vs 干预
03COUNTERFACTUAL REASONING

反事实推理

潜在结果框架：每个个体同时存在 Y(1) 与 Y(0)，但只能观测到其中一个。反事实即"如果处理不同会怎样"。点击个体查看其个体处理效应（ITE），切换显示反事实结果，对比 ITE、ATE 与 ATT。

潜在结果与反事实
04PROPENSITY SCORE MATCHING

倾向得分匹配

估计倾向得分 e(X)=P(T=1|X)，按倾向得分将处理组与对照组匹配，消除可观测混杂。切换匹配方法（最近邻/分层/IPTW），调节卡钳宽度，观察匹配前后协变量平衡的改善与处理效应估计。

匹配与平衡诊断
05INSTRUMENTAL VARIABLES

工具变量

工具变量 Z 仅通过 X 影响 Y（排他性约束），且与 X 强相关（相关性条件）。两阶段最小二乘（2SLS）先用 Z 预测 X，再回归 Y，从而在存在未观测混杂时获得无偏的 LATE 估计。调节工具变量强度与混杂强度。

2SLS 与排他性约束
06CAUSAL DISCOVERY

因果发现

从观测数据中自动学习因果结构。PC 算法基于条件独立性检验（约束式），GES 基于评分搜索，LiNGAM 利用非高斯性确定全部方向。点击播放可逐步动画演示 PC 算法如何从完全图开始，通过检验移除边、识别 v-结构并传播方向。

结构学习动画
07DIFFERENCE-IN-DIFFERENCES

双重差分 (DiD)

利用处理组与对照组在政策前后的变化之差来识别因果效应，核心假设是平行趋势。拖动滑块改变处理时点与效应大小，观察反事实趋势线（虚线）与 DiD 估计，并检验政策前两组斜率是否平行。

平行趋势与反事实
08ESTIMATOR COMPARISON

因果效应估计对比

横向对比六种估计方法：RCT（金标准）、回归调整、IPW、双重稳健、匹配、工具变量。调节数据生成过程中的混杂强度，观察各方法的偏差、方差与 MSE 排名如何变化。垂直虚线为真实效应。
