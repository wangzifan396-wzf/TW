拍卖理论 Auction Theory

Vickrey 二价拍卖中真实出价是占优策略；First-Price 一价拍卖均衡需向下压价。收益等价定理：风险中性下两者期望收益相同。切换拍卖类型观察出价与支付差异。

收益等价定理

在 IPV 模型与风险中性假设下，任何满足对称性、正则性的拍卖机制，若分配规则相同（最高价中标），则期望收益相等。Vickrey 支付第二高价，First-Price 均衡出价 b = (n-1)/n · v。

MODULE 03

VCG 机制 Vickrey-Clarke-Groves

VCG 选择社会剩余最大化的分配，每人为其施加的外部性付费（Clarke pivot）。是激励相容的直接机制。调整各投标者估值，观察分配与 VCG 支付。

vcg-mechanism.svg

Clarke 支付规则

VCG 分配 x* = argmax Σ vᵢ(x)。每个投标者支付其外部性：tᵢ = Σⱼ≠ᵢ vⱼ(x₋ᵢ*) − Σⱼ≠ᵢ vⱼ(x*)。即“没有你时别人的福利”减“有你时别人的福利”。该规则保证真实报告是占优策略。

MODULE 05

纳什均衡存在性 Nash Existence

有限博弈必存在混合策略纳什均衡。证明依赖 Kakutani 不动点定理：最优反应对应在单纯形上有凸值闭图，必有不动点。调整收益矩阵，观察最优反应曲线交点。

nash-kakutani.svg
玩家 1 最优反应 玩家 2 最优反应 纳什均衡

Kakutani 不动点定理

设 C 为非空紧凸集，F: C → 2ᶜ 为集值映射，图像闭且 F(x) 非空凸，则存在 x* 使 x* ∈ F(x*)。在博弈中 C = 单纯形积，F = 最优反应对应，不动点即纳什均衡。

MODULE 06

重复博弈 Repeated Games

无限重复博弈中，折扣因子 δ 决定合作可维持性。Grim Trigger：一旦对手背叛则永久背叛；Tit-for-Tat：复制对手上轮行动。播放回合观察策略轨迹与累计收益。

repeated-game.svg
合作 C 背叛 D 玩家 1 累计 玩家 2 累计

无名氏定理 Folk Theorem

对足够大的 δ，无限重复博弈的子博弈完美均衡可支撑任何个人理性收益。Grim Trigger 维持合作条件：δ ≥ (T−R)/(T−P)，其中 R 为互相合作收益，T 为背叛诱惑，P 为互相惩罚。

MODULE 07

演化博弈 Evolutionary Games

ESS 进化稳定策略：群体中占多数时，突变策略无法入侵。复制动态方程 ẋ = x(f(x) − f̄) 描述策略频率演化。调整收益矩阵，观察单纯形中的轨迹。

evolutionary-game.svg
策略 A 策略 B ESS / 稳定不动点 不稳定不动点

ESS 判据

策略 x* 是 ESS 当且仅当：① x* 是纳什均衡；② 对任意最优反应 y≠x*，有 u(x*,x*) > u(y,x*)，或 u(x*,x*) = u(y,x*) 且 u(x*,y) > u(y,y)。复制动态的不动点即纳什均衡，渐近稳定者即 ESS。

MODULE 08

匹配市场 Matching Markets

Gale-Shapley 延迟接受算法：一方依次求婚，另一方暂时保留最优提议。算法必然终止于稳定匹配（无阻塞对）。单步执行观察求婚与接受过程。

gale-shapley.svg
求婚方 A 被求婚方 B 当前暂定匹配 本轮求婚

稳定匹配 Stable Matching

匹配 μ 稳定当且仅当不存在阻塞对 (a,b)：a 偏好 b 胜过 μ(a)，且 b 偏好 a 胜过 μ(b)。Gale-Shapley 必在 O(n²) 内终止。男求婚后结果是男最优稳定匹配，女求婚则是女最优。
