MODULE 01

ControlNet · 条件控制引导

将条件信号（Canny 边缘、Depth 深度、Pose 姿态）通过可训练副本 + zero convolution 注入 U-Net。调节控制强度，观察条件对生成结果的引导程度。

controlnet-inject.svg
条件信号 ControlNet 副本 zero conv U-Net 主干

ControlNet 注入原理

克隆 U-Net 编码层得到可训练副本，输入端接入条件图。输出经 zero convolution（初始权重为 0）加回主网络。训练初期不影响原模型，逐步学习条件引导。控制强度 scale 调节注入幅度。

MODULE 03

LoRA · 低秩适配器微调

冻结原权重 W₀，仅训练低秩矩阵 B×A。W = W₀ + BA。调节 rank 与多 LoRA 合并权重，观察参数效率与生成效果。

lora-decompose.svg
W₀（冻结） B (d×r) A (r×d) 多 LoRA 合并

低秩分解 W = W₀ + BA

原权重 d×d = n² 参数；LoRA 分解为 B(d×r)+A(r×d)=2dr 参数，当 r≪d 时大幅降低。多个 LoRA 可按权重线性合并：W = W₀ + Σ αᵢ BᵢAᵢ，实现风格混搭。

MODULE 05

CFG Scale · Classifier-Free Guidance

同时预测条件 εθ(xt, c) 与无条件 εθ(xt, ∅)，按 guidance scale 放大条件方向。调节 w 观察采样轨迹偏离无条件路径的程度。

cfg-scale.svg
条件路径 无条件路径 CFG 合成轨迹 guidance w

CFG 公式

ε̃ = εθ(xt,∅) + w·(εθ(xt,c) − εθ(xt,∅))。w=1 时退化为普通条件采样；w>1 放大条件方向，提升 prompt 相关性但减少多样性；w 过高导致过饱和与伪影。

MODULE 07

Img2Img · 图像到图像生成

输入图像加噪到 denoise strength 对应的步数，再用扩散模型去噪重绘。调节 strength 控制保留原图与重绘的比例。

img2img.svg
原图信息 噪声 重绘生成 denoise

denoise strength 含义

strength=0 时完全保留原图；strength=1 时加满噪声、等同于 text2img；0.3-0.6 适合风格转换与局部重绘。实际加噪步数 = round(T · strength)，从该步开始反向去噪。

MODULE 08

超分辨率 · 低清到高清

T2I-Adapter 与 Upscaler 将低分辨率生成提升至高清。调节放大倍数，对比双三次插值与扩散超分的细节恢复能力。

upscale.svg
低清输入 双三次插值 扩散超分 新增细节

扩散超分原理

双三次插值仅放大像素、无法补充高频细节；扩散超分将低清图作为条件，在 latent 空间加噪去噪，生成符合语义的高频纹理。T2I-Adapter 注入结构条件，Upscaler 直接预测残差。
