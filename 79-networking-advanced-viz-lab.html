SDN 软件定义网络

控制平面 / 数据平面分离，流表下发

原理说明

SDN 将网络设备的控制平面（决策）与数据平面（转发）分离。控制器集中管理全网视图，通过 OpenFlow 南向协议向交换机下发流表。

  • 南向接口：OpenFlow，流表 = 匹配字段 + 动作
  • 北向接口：REST API，应用编程网络行为
  • 流表下发：控制器 → 交换机，定义转发规则

当主机 A 向主机 F 发送数据时，数据包按照流表规则在交换机间转发，无需逐跳路由决策。

  • Proactive 模式：预先下发流表，低延迟
  • Reactive 模式：首包触发 Packet-In 请求
  • 优势：集中管控、快速迭代、流量工程

BGP 路由

AS 间路由，路径选择，路由聚合

原理说明

BGP (Border Gateway Protocol) 是互联网骨干路由协议，负责自治系统 (AS) 间的路由信息交换。

  • eBGP：跨 AS 边界的 BGP 会话
  • iBGP：AS 内部的 BGP 会话
  • 路径矢量：携带 AS-Path 属性防环

BGP 最优路径选择基于多属性优先级：

  • Local Pref → AS-Path 长度 → MED → EBGP > IBGP
  • 路由聚合：将多条明细路由汇总为 /22 超网前缀
  • 减少路由表规模，隔离翻动传播

QoS 服务质量

DSCP 标记，队列调度 (WFQ / PQ / CBQ)

速率

原理说明

QoS 通过DSCP 标记对流量分类，再由调度算法分配带宽资源。

  • EF (46)：低延迟、低抖动，语音/视频
  • AF (10-38)：保证带宽，有丢弃优先级
  • BE (0)：尽力而为，普通数据

三种经典调度算法：

  • PQ：严格优先级，高优先先发，可能饿死低优先
  • WFQ：按权重分配带宽，公平但保优先
  • CBQ：基于类，可为每类保证/限制带宽

CDN 内容分发

就近节点选择，缓存命中，回源

原理说明

CDN 通过在全球部署边缘节点，将内容缓存到离用户最近的节点，降低延迟和源站压力。

  • DNS 调度：根据用户位置解析到最近边缘
  • 缓存命中：直接从边缘返回，无需回源
  • 回源：缓存未命中时向源站请求

CDN 的关键指标和机制：

  • 命中率：命中请求 / 总请求，通常 > 90%
  • TTL：缓存生存时间，过期后回源刷新
  • 预热：主动推送内容到边缘节点

IPv6

地址结构，SLAAC，DHCPv6，双栈

原理说明

IPv6 地址为 128 位，分为全局前缀、子网 ID 和接口 ID。

  • SLAAC：主机通过 RS/RA 自动配置，无需 DHCP
  • DHCPv6：有状态配置，服务器分配地址
  • EUI-64：由 MAC 地址生成接口 ID

IPv6 过渡技术：

  • 双栈：同时运行 IPv4/IPv6，优先 IPv6
  • 隧道：6to4 / 6rd / GRE 隧道
  • NAT64：IPv6-only 访问 IPv4 资源
  • DAD：重复地址检测保障唯一性

负载均衡

L4 / L7 负载均衡，一致性哈希，健康检查

原理说明

负载均衡将流量分发到多台后端服务器，提升可用性和吞吐量。

  • L4：基于 IP + 端口，速度快，不解析内容
  • L7：基于 HTTP URL/Header/Cookie，智能路由
  • 一致性哈希：节点增减时最小化数据迁移

健康检查与调度策略：

  • 主动检查：定期探测后端健康状态
  • 被动检查：根据请求失败率自动摘除
  • 加权轮询：按服务器能力分配权重
  • 最少连接：优先分配给连接数少的节点

网络安全

DDoS 防护，WAF 规则，零信任

原理说明

现代网络安全采用纵深防御策略，多层过滤恶意流量。

  • DDoS 防护：流量清洗中心，BGP Anycast 分散攻击
  • WAF：匹配 SQL 注入 / XSS / CC 等攻击特征
  • 零信任：永不信任，始终验证 (NIST 800-207)

零信任核心原则：

  • 身份为中心：基于用户/设备身份授权
  • 最小权限：仅授予完成任务所需权限
  • 微隔离：网络分段，限制横向移动
  • 持续验证：动态评估信任级别

无线网络

WiFi 信道，CSMA/CA，漫游，MIMO

原理说明

WiFi 使用 CSMA/CA（载波监听多路访问/冲突避免）协议共享无线信道。

  • DIFS：分布式帧间间隔，等待信道空闲
  • Backoff：随机退避，减少冲突概率
  • SIFS：短帧间间隔，用于 ACK 响应
  • RTS/CTS：解决隐藏终端问题

信道、漫游与 MIMO：

  • 信道重叠：2.4GHz 仅 CH1/6/11 互不干扰
  • 漫游：802.11r/k/v 快速切换 AP
  • MIMO：多天线空间复用，提升吞吐
  • OFDMA：WiFi 6 子载波分配，降低延迟
