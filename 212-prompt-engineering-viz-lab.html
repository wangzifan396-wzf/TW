提示工程系统化可视化实验室

从零试错到系统工程——把 2026 年提示工程如何从手工艺演进为可度量、可优化的工程方法论的核心机制以可交互 SVG 呈现。

01

提示工程全景

PE 的成熟度层次：基础 Prompt → Few-shot → Chain-of-Thought → Self-Consistency → Prompt 链 → 自动优化。点击按钮逐层展开能力金字塔。

02

Few-shot 示例选择

示例选择策略：随机 → 相似度 → 多样性 → 投票选择 → 自动示例优化。在示例空间中观察不同策略如何覆盖候选示例。

03

思维链变体

CoT 家族：Zero-shot CoT → Few-shot CoT → Self-Consistency → Tree-of-Thought → Graph-of-Thought。观察不同推理结构的拓扑差异。

04

Prompt 模板工程

结构化模板设计：角色设定 → 任务描述 → 输出格式 → 约束条件 → 示例 → 变量插槽。逐个高亮模板组件观察其作用。

05

自动 Prompt 优化

APO 方法谱系：梯度搜索 → Monte Carlo → 进化算法 → Prompt Tuning → Soft Prompt。切换方法观察优化流程差异。

06

Prompt 安全与鲁棒性

Prompt 注入防御：输入清洗 → 指令隔离 → 输出过滤 → 红队测试。逐层激活防御策略观察拦截效果。

07

Prompt 评估体系

Prompt 质量多维评估：准确率 → 一致性 → 鲁棒性 → 效率 → 可迁移性。切换维度观察不同 Prompt 在雷达图上的表现。

08
