网络安全可视化实验室

通过 8 个交互式 SVG 可视化模块，直观呈现常见网络攻击原理与防御机制：DDoS、SQL 注入、XSS/CSRF、渗透测试、WAF、IDS/IPS、蜜罐与零信任架构。所有图形均由原生 SVG + JavaScript 实时绘制，零外部依赖。

8 Modules SVG + Vanilla JS Zero Dependencies Single File
01DISTRIBUTED DENIAL OF SERVICE

DDoS 攻击与防御

僵尸网络向目标服务器发送海量流量，容量型耗尽带宽、协议型耗尽连接状态、应用层耗尽应用资源。防御侧通过 CDN 分流、速率限制与流量清洗过滤恶意报文。

攻击流量与防御过滤
02SQL INJECTION

SQL 注入

攻击者通过构造恶意输入篡改 SQL 查询逻辑，进而读取、篡改或删除数据库内容。常见类型包括 UNION 注入、报错注入、布尔盲注、时间盲注与带外注入。

注入流程与数据外泄
03XSS & CSRF

XSS 与 CSRF

跨站脚本攻击(XSS)向页面注入恶意脚本窃取用户数据，分为存储型、反射型与 DOM 型；跨站请求伪造(CSRF)诱导已登录用户在不知情下执行敏感操作。

脚本注入与会话劫持
04PENETRATION TESTING

渗透测试流程

完整的渗透测试涵盖侦察、扫描、漏洞利用、后渗透与报告五个阶段。可视化展示网络拓扑发现、端口扫描、漏洞识别与权限提升过程。

网络拓扑与漏洞发现
05WEB APPLICATION FIREWALL

Web 应用防火墙 WAF

WAF 在 HTTP 请求到达应用前进行规则匹配，对恶意请求执行拦截、质询或记录。规则类型涵盖特征匹配、行为分析与机器学习模型。

规则匹配流水线
06INTRUSION DETECTION

入侵检测 IDS/IPS

入侵检测系统监控网络或主机活动，基于特征签名(Snort 规则)或异常行为(机器学习模型)识别攻击，NIDS 部署于网络旁路，HIDS 部署于主机代理。

流量检测与告警
07HONEYPOT

蜜罐 Honeypot

蜜罐部署伪装服务(SSH、Web、数据库)诱捕攻击者，记录其探测、爆破与横向移动行为，提取战术、技术与程序(TTP)及威胁情报指标。

诱捕与行为分析
08ZERO TRUST ARCHITECTURE

零信任架构

零信任遵循"永不信任，始终验证"原则，结合身份验证、设备健康度、微分段与持续监控，每次访问均经策略引擎动态评估与多因素认证。

动态访问策略评估
