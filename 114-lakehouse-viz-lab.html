数据湖与湖仓一体 可视化实验室

用交互式 SVG 呈现数据湖架构、Iceberg/Delta Lake 表格式、数据分层、查询引擎等湖仓一体核心技术。八个模块，纯原生实现。

MODULE 01

数据湖架构与对象存储

HDFS / S3 对象存储承载海量原始数据。缺乏治理的数据湖退化为“数据沼泽”；加上目录、Schema 与访问控制才是真正的数据湖。切换观察差异。

data-lake.svg
已编目 未治理 结构化 非结构化

数据湖 vs 数据沼泽

数据沼泽：数据随意堆放、无 Schema、无目录、无人能找到。数据湖：通过 Catalog（如 Hive Metastore / Glue）登记、打标、设权限，数据可被发现与信任。

MODULE 03

Iceberg 表格式与时间旅行

Iceberg 用 metadata.json → manifest list → manifest → data file 的分层元数据管理表。每个快照对应一次表状态，支持时间旅行与回滚。

iceberg-manifest.svg
metadata manifest list manifest data file

快照与时间旅行

选择不同快照查看表在该时间点的数据文件组成。manifest 记录每个 data file 的分区与统计信息，查询计划时只读取相关 manifest，无需列举全部文件。

MODULE 05

数据分层：Medallion 架构

Bronze（原始）→ Silver（清洗）→ Gold（聚合）逐层提纯。越往上层质量越高、越贴近业务，记录数可能减少但价值密度提升。

medallion.svg
Bronze 原始 Silver 清洗 Gold 聚合 质量

Medallion 分层

Bronze 落地原始数据（含脏数据/重复）；Silver 去重、类型校正、关联；Gold 按业务域聚合，供 BI 直接消费。点击各层查看其处理动作与质量。

MODULE 06

Schema 演化与合并

开放表格式支持 Schema Evolution：新增列对旧文件读为 NULL；Schema Merge 合并不同版本分区。无需重写历史数据即可演进。

schema-evolution.svg
新增列 删除列 改名列 NULL 填充

Schema 版本

点击“新增列/删除列/改名”演进 Schema。新列对旧文件读出 NULL，旧列对新文件保留兼容。MERGE SCHEMA 自动合并写入门禁。
