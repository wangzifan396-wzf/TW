搜索引擎可视化实验室

通过 8 个交互式可视化模块，拆解现代搜索引擎的核心机制：从倒排索引的构建、TF-IDF / BM25 的相关性评分，到 PageRank 的链接分析与爬虫架构，再到查询解析、分词标准化与 Rocchio 相关性反馈。全部基于 SVG 与原生 JS，零外部依赖。

8 Modules SVG + Vanilla JS Zero Dependencies Single File
01INVERTED INDEX

倒排索引

将文档集合转化为 term → postings list 的映射结构。左侧为按字典序排列的词项字典，右侧展示选中词项的倒排表（文档 ID 与位置），并标注跳表指针以加速交并运算。

索引结构可视化
02TF-IDF SCORING

TF-IDF 评分

词频（TF）衡量词项在文档中的出现频率，逆文档频率（IDF）衡量词项的区分能力。TF-IDF = TF × IDF，是经典的相关性加权方法。

TF / IDF / TF-IDF 分析
03BM25 RANKING

BM25 排序

BM25 在 TF-IDF 基础上引入词频饱和与文档长度归一化。公式：score = IDF × (f·(k1+1)) / (f + k1·(1 − b + b·|D|/avgdl))。调节 k1 与 b 可显著改变排序结果。

BM25 评分与公式拆解
04PAGERANK

PageRank

在网页有向图上迭代传播排名：r = (1−d)/N + d·Σ(r_in/out_deg)。阻尼因子 d 通常取 0.85。节点大小反映当前 PageRank 值，边上的流光展示排名传递过程。

链接图与迭代收敛
05WEB CRAWLER

爬虫架构

URL 前沿队列 → robots.txt 检查 → 抓取器 → 解析器 → 索引。解析阶段抽取新链接并去重后回填前沿队列。深度参数控制爬取层数。

爬取流水线
06QUERY PROCESSING

查询处理

将用户查询解析为可执行结构：布尔查询构造 AST（AND/OR/NOT），短语查询保留位置顺序，模糊与通配查询进行扩展。随后在倒排索引上执行并返回匹配文档。

查询解析与执行
07TOKENIZATION & NORMALIZATION

分词与标准化

文本处理流水线：原文 → 分词 → 小写化 → 词干提取 → 去停用词。每个阶段可独立开关，观察词汇表与保留词项的变化。

处理流水线
08RELEVANCE FEEDBACK

相关性反馈

Rocchio 算法：q' = α·q + β·(1/|Dr|)·Σdr − γ·(1/|Dnr|)·Σdnr。将查询向量移向相关文档、远离无关文档。点击文档切换其相关 / 无关标签后应用反馈，观察查询向量移动与召回率提升。
