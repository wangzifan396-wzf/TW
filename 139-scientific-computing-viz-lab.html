01偏微分方程数值解 · 热传导方程

显式 FTCS 格式求解 ∂u/∂t = α ∂²u/∂x²。稳定性条件 r = α·Δt/Δx² ≤ 0.5，超过即数值发散。调节 r 观察稳定与失稳。

r = αΔt/Δx² 0.25 稳定
r ≤ 0.5 时显式格式稳定；r > 0.5 时高频误差指数增长，解迅速发散。隐式格式无条件稳定但需解线性方程组。

05快速多极子法 (FMM) · N-body 加速

N 体问题直接计算 O(N²)。FMM 用层次多极展开，远场聚合、近场直接算，复杂度降至 O(N)。切换观察交互模式。

直接 O(N²)
FMM O(N)
直接法绘制所有 N(N-1)/2 条相互作用；FMM 用四叉树划分空间，仅近邻直接算，远场用多极展开合并。
