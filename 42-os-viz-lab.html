操作系统内核可视化实验室

将进程调度、虚拟内存、磁盘 I/O、文件系统、同步互斥、中断处理、内存分配与写时复制等内核机制，转化为可交互、可动画的 SVG 可视化场景。纯单文件 HTML/CSS/JS，零外部依赖。

8 Modules SVG + Vanilla JS Zero Dependencies Single File
01PROCESS SCHEDULING

进程调度算法

可视化 CPU 调度：FCFS、SJF、Round Robin、Priority、多级反馈队列（MLFQ）。通过甘特图展示进程执行时间线，动画演示进程到达、调度、执行与等待过程。

调度甘特图
02VIRTUAL MEMORY

内存管理 - 页表与虚拟内存

可视化虚拟地址到物理地址的翻译过程：TLB 查找、页表遍历、缺页处理。动画演示 CPU 生成虚拟地址后，经 TLB、页表访问物理内存或触发缺页中断的完整路径。

地址翻译流程
03DISK I/O SCHEDULING

磁盘 I/O 调度

可视化磁盘调度算法：FCFS、SSTF、SCAN、C-SCAN、LOOK、C-LOOK。展示磁盘柱面与读写磁头移动，动画演示请求队列与磁头寻道过程。

磁头寻道轨迹
04FILE SYSTEM

文件系统 - inode 与目录结构

可视化 inode 结构：元数据 + 直接/一级间接/二级间接/三级间接块指针。展示目录树与文件分配策略（连续、链接、索引），动画演示文件读写遍历块指针。

inode 与数据块映射
05SYNCHRONIZATION

互斥锁与同步

可视化互斥锁、信号量、管程、条件变量。展示多线程竞争锁、阻塞与唤醒过程，动画演示线程获取锁、其他线程等待、释放唤醒下一个的完整流程。

线程竞争与临界区
06INTERRUPTS

中断与异常处理

可视化中断处理流程：中断 → 保存上下文 → ISR → 恢复上下文。展示中断向量表（IVT）、优先级与嵌套中断，动画演示硬件中断发生、CPU 保存状态、跳转 ISR、返回的过程。

中断处理流水线
07MEMORY ALLOCATION

内存分配 - 伙伴系统与 Slab

可视化伙伴系统分配：块的分裂与合并（2 的幂）。展示 Slab 分配器：缓存、slab、空闲/部分/满。动画演示分配时分裂块、释放时合并伙伴的过程。

分配器状态视图
08COPY-ON-WRITE

写时复制 COW

可视化 fork() 的写时复制机制。父进程页面与子进程共享（只读），写操作触发 COW 缺页并复制页面。动画演示 fork 创建共享页、写触发缺页、分配新页的过程。
