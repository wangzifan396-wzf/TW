Instatic is an open-source self-hosted visual CMS built on Bun runtime, designed to replace Webflow and WordPress. It integrates a canvas visual editor, core design system framework, AI page builder agent, data table management, and an extensible QuickJS-WASM sandbox plugin system. Supports SQLite and Postgres databases. On publish, it generates semantic HTML and lightweight CSS files saved to disk with zero framework runtime dependencies.
