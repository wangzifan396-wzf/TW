## 交互功能

TW Hub 内置丰富的交互体验，所有状态通过 localStorage 本地持久化：

| 功能 | 说明 | 操作方式 |
|------|------|----------|
| 深色/浅色主题 | 一键切换，自动记忆偏好 | 点击导航栏月亮按钮 / 按 `T` 键 |
| 探索进度追踪 | 点击 Demo 自动标记已探索，显示进度条和百分比 | 点击任意项目的「打开 Demo」 |
| 最近浏览 | 记录最近 12 个浏览过的项目，横向滚动展示 | 自动追踪，点击即可回顾 |
| 实时搜索 | 按项目名称、关键词、描述搜索 | 输入框输入 / 按 `/` 键聚焦 |
| 分类筛选 | AI/系统/理论/交叉学科一键过滤 | 点击分类标签 |
| 多维排序 | 默认/编号升降序/按分类 | 下拉选择 |
| 随机探索 | 随机打开一个项目 | 点击骰子 / 按 `R` 键 |
| 键盘导航 | 上下浏览项目卡片，回车打开 | `J`/`K` 或方向键 |
| 动画计数器 | 首屏数字从 0 滚动到目标值 | 滚动到可视区域自动触发 |
| 滚动进度条 | 顶部渐变色条显示页面阅读进度 | 自动 |
| 快捷键帮助 | 弹出所有快捷键说明 | 按 `?` 键 |
| 数据仪表盘 | SVG 环形图 + 动画柱状图展示分类分布 | 滚动到仪表盘区域 |

## 技术栈

- 纯 HTML / CSS / JavaScript，零外部依赖
- SVG 数据可视化
- Linear 工程冷峻美学
- 响应式设计，支持 `prefers-reduced-motion`

## 设计原则

- **零依赖** — 不引用任何 CDN、框架或库，永远不会因上游变更而 break
- **单文件** — 每个项目就是一个 `index.html`，复制到任何地方都能运行
- **交互式** — 不是静态图，每个模块都有动画、滑块、按钮
- **高性能** — 全 `transform` 驱动动画，`requestAnimationFrame` 节流，无 `backdrop-filter`
