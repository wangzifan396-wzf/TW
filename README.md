## 技术架构

每个可视化实验室采用统一架构：

- **8 模块 × 3 视图** — 每个项目 24 个独立可视化场景
- **零依赖** — 不引用任何 CDN、框架或库，永远不会因上游变更而 break
- **单文件** — 每个项目就是一个 HTML 文件，复制到任何地方都能运行
- **SVG 可视化** — 原生 SVG 绘图，CSS 动画驱动，`requestAnimationFrame` 节流
- **交互式** — 不是静态图，每个模块都有动画、切换、实时渲染
- **暗色主题** — 统一的设计语言，CSS 变量驱动配色系统
- **响应式** — 支持桌面和移动端，`prefers-reduced-motion` 友好

### 统一工具函数

所有项目共享一致的 JavaScript 工具函数库：`E()` 创建 SVG 元素、`box()` 绘制矩形、`txt()` 绘制文本、`arrow()` 绘制箭头、`radar()` 绘制雷达图、`gridBg()` 绘制网格背景、`setPills()/setLegend()/setInfo()` 渲染侧边栏信息面板。
