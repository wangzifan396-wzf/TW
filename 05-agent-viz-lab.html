01

Agent 循环架构

Agent 的核心是「感知 → 思考 → 行动」循环。观察环境输入，LLM 推理决策，执行工具调用，观察结果反馈，循环往复直到任务完成。

02

ReAct 推理模式

ReAct (Reasoning + Acting) 将推理与行动交错执行：Thought → Action → Observation 循环，让 Agent 边想边做，逐步逼近答案。

03

工具调用与函数选择

Function Calling 让 LLM 选择正确的工具并提取参数。可视化工具注册表、选择概率和参数提取过程。

04

规划策略对比

Chain-of-Thought (CoT)、Tree-of-Thoughts (ToT)、Graph-of-Thoughts (GoT) 三种规划策略的结构与权衡。

05

Agent 记忆系统

短期记忆 (上下文窗口)、长期记忆 (向量数据库)、情景记忆 (经验回放) 三层记忆架构。

06

多智能体协作模式

Supervisor (主管)、Peer-to-Peer (对等)、Hierarchical (层级) 三种多 Agent 协作架构。

07

安全护栏与防护

输入过滤、输出审查、越狱防护、权限控制 — Agent 安全的四道防线。

08

评估与可观测性

Agent 评估指标体系：任务成功率、工具调用准确率、平均步数、Token 消耗。可观测性 Trace 链路追踪。
