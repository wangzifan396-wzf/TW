时间序列预测可视化实验室

从经典统计到深度学习，8 个交互式 SVG 模块系统化拆解时间序列预测的核心模型：ARIMA 与指数平滑、Prophet 分解、DeepAR 概率自回归、PatchTST、TFT、N-BEATS，以及概率区间与模型对比基准。全部纯 SVG 绘制，零依赖，可交互调参与动画演示。

8 Modules SVG + Vanilla JS Zero Dependencies Single File
01ARIMA / EXPONENTIAL SMOOTHING

ARIMA 分解与指数平滑

ARIMA(p,d,q) 将序列分解为趋势、季节与残差三部分；Holt-Winters 指数平滑对未来做加权外推。调节 p/d/q 与季节周期，观察预测如何随置信区间逐步展开。

ARIMA 分解 + 预测置信区间
02PROPHET DECOMPOSITION

Prophet 模型分解

Prophet 将序列建模为趋势（线性/逻辑增长）、季节性（日/周/年）、节假日效应与残差之和。切换加法/乘法模式与趋势类型，观察变点如何分段拟合趋势。

Prophet 趋势 · 季节 · 节假日 · 残差
03DEEPAR · DEEP AUTOREGRESSIVE

DeepAR 深度自回归概率预测

DeepAR 用自回归神经网络在每一步输出一个高斯分布（均值 μ 与方差 σ²），而非单点。逐步采样生成多条轨迹，形成分位数区间。观察分布如何沿时间轴逐点展开。

逐步分布生成 · 分位数轨迹
04PATCHTST · TRANSFORMER FOR TS

PatchTST 分块 Transformer

将序列切分为固定长度的 patch 再嵌入，大幅缩短序列长度，降低 Transformer 注意力的二次开销。调节 patch 长度与步长，对比“逐步 token”与“分块 token”的序列规模与注意力连接。

序列 → Patch → Embedding → Encoder → 预测
05TEMPORAL FUSION TRANSFORMER

Temporal Fusion Transformer

TFT 用变量选择网络（VSN）为不同输入分配权重，门控残差网络（GRN）做非线性融合，时序注意力捕捉长程依赖。静态元数据绕过时序注意力直达输出，已知未来输入则参与解码。

VSN · GRN · Temporal Attention 数据流
06N-BEATS ARCHITECTURE

N-BEATS 基函数展开

N-BEATS 由多个堆叠 block 组成，每个 block 共享 MLP 并输出前向预测与后向预测。前向预测从输入残差中扣除，残差再传入下一 block。可解释基函数把预测分解为趋势与季节分量。

Stack 残差链 · 前向/后向预测 · 基函数
07PROBABILISTIC FORECASTING

概率预测与区间校准

概率预测输出完整分布而非单点：以分位数（P10/P50/P90）刻画区间。用 pinball loss 训练，用覆盖度校准——90% 的真实值是否真的落在 P5–P95 之间？

分位扇形图 · Pinball 损失 · 校准曲线
08MODEL BENCHMARK

模型对比基准

在同一条时间序列上并列对比六种模型：ARIMA、Prophet、DeepAR、PatchTST、TFT、N-BEATS。切换数据集类型（趋势/季节/不规则）与预测步长，观察误差指标与排名变化。

六模型并列预测 · 误差指标表
