02 / PLANNING

轨迹规划

基于采样的路径规划算法可视化。RRT 随机扩展搜索树，RRT* 通过重新连接渐进收敛最优路径，PRM 预构建路线图支持多次查询。

Sampling-based Planning
算法
步长20
速度3

原理：采样路径规划

RRT：从起点出发，每次随机采样 q_rand，找到树上最近节点 q_near，向 q_rand 方向扩展步长得到 q_new。若无碰撞则加入树。

RRT*：在 RRT 基础上检查 q_new 邻域，若有节点经 q_new 到达根节点更近则重新连接父节点，保证渐近最优。

PRM：预采样 N 个无碰撞点，连接 k 近邻构建 roadmap，再用 A*/Dijkstra 查询路径。

03 / SLAM

SLAM 进阶

同步定位与建图。粒子滤波 SLAM 用粒子集表示位姿后验分布；GraphSLAM 将位姿与地图建模为因子图进行联合优化。

SLAM Simulation
SLAM 方法
粒子数150
运动噪声3

原理：粒子滤波与图优化 SLAM

粒子滤波 SLAM：用粒子集 {xₜ⁽ⁱ⁾, wₜ⁽ⁱ⁾} 表示位姿后验。每步执行运动更新→测量更新→重采样。

运动: xₜ = f(xₜ₋₁, uₜ) + ε
权重: wₜ ∝ p(zₜ | xₜ, m) · wₜ₋₁
重采样: 低权重淘汰，高权重复制

GraphSLAM：将所有位姿与路标构建为因子图，节点间约束来自运动模型和观测，通过最小化残差全局优化。

04 / CONTROL

MPC 控制

模型预测控制：在每时刻求解有限时域优化问题，预测未来 N 步系统演化，在约束下最小化代价函数，仅执行第一步控制。

Model Predictive Control
预测时域 N10
速度2.0
跟踪权重 Q1.0
控制权重 R0.1

原理：滚动时域优化

在时刻 t，基于系统模型预测未来 N 步状态序列，最小化代价函数 J，求解最优控制序列 {u₀, u₁, ..., u_{N-1}}，仅执行 u₀，下一时刻重复。

J = Σₖ (||xₜ₊ₖ - x_ref||²_Q + ||uₜ₊ₖ||²_R)
s.t. xₘᵢₙ ≤ x ≤ xₘₐₓ, uₘᵢₙ ≤ u ≤ uₘₐₓ

无人车模型：ẋ = v·cos(θ), ẏ = v·sin(θ), θ̇ = ω

05 / VISION

视觉伺服

利用视觉反馈控制机器人运动。IBVS 在图像平面最小化特征误差，PBVS 估计 3D 位姿后控制。图像雅可比矩阵关联图像变化与相机速度。

Visual Servoing
伺服模式
增益 λ0.05
特征点数4

原理：图像雅可比与视觉伺服

IBVS：直接在图像平面控制特征点 s 向期望位置 s* 收敛。控制律基于图像雅可比 J 的伪逆。

ṡ = J(s) · v
v = -λ · J⁺(s) · (s - s*)
e = s - s* → 0

PBVS：从图像估计目标 3D 位姿，在笛卡尔空间设计控制律驱动位姿误差归零。

Impedance Control
刚度 K50
阻尼 B5

原理：阻抗与导纳控制

阻抗控制令机器人末端等效为质量-阻尼-刚度系统，期望动力学方程如下：

M ẍ + B ẋ + K(x - x_d) = F_ext
当 x > x_wall: F_ext = -K_env·(x - x_wall)

导纳控制：测量外力 F_ext，计算位置偏移再进行位置控制。力位混合：法向力控、切向位控，适用于打磨、装配等任务。
