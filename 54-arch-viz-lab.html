计算机体系结构可视化实验室

通过 8 个交互式 SVG 可视化模块，探索现代计算机体系结构的核心机制：从 CPU 流水线、Cache 层次、分支预测，到乱序执行、指令级并行、内存层次、SIMD 向量以及 Roofline 性能模型。所有模块均可实时交互调节参数，观察体系结构行为的变化。

8 Modules SVG + Vanilla JS Zero Dependencies Single File
01CPU PIPELINE

CPU 流水线

经典 5 级流水线（IF / ID / EX / MEM / WB）的指令时空图可视化。展示数据冒险与结构冒险，对比前递（forwarding）与插入 NOP 气泡两种解决策略对吞吐率的影响。

流水线时空图
02CACHE HIERARCHY

Cache 层次结构

L1 / L2 / L3 三级缓存与主存的访问路径可视化。调节缓存容量、相联度与访问模式，观察命中率与平均访问时间（AMAT）的变化，理解空间与时间局部性原理。

缓存访问与命中率
03BRANCH PREDICTION

分支预测

对比 1-bit、2-bit 饱和计数器与 Tournament 锦标赛预测器。输入分支模式序列，观察预测状态机的迁移与预测准确率，理解为什么 2-bit 预测器在嵌套循环中表现更优。

预测器状态机与历史表
04OUT-OF-ORDER EXECUTION

乱序执行

基于 Tomasulo 算法的保留站、功能单元与公共数据总线（CDB）可视化。指令发射、执行与写回的动态调度过程，展示乱序执行如何利用指令级并行度提升性能。

Tomasulo 调度
05INSTRUCTION-LEVEL PARALLELISM

指令级并行

循环展开、向量化与超标量发射的指令调度对比。调节展开因子与发射宽度，观察并行指令槽的利用情况与加速比，理解 ILP 的上限受限于数据依赖与硬件资源。

并行指令调度槽
06MEMORY HIERARCHY

内存层次

寄存器到磁盘的延迟金字塔与带宽梯度可视化。切换各层可见性与访问模式，直观感受跨越 7 个数量级的访问延迟差异，理解存储墙（memory wall）问题的根源。

延迟金字塔与带宽
07SIMD / VECTOR

SIMD 向量

单指令多数据流（SIMD）向量指令对数组元素并行处理的可视化。切换向量宽度（128/256/512-bit）与数据类型，观察向量通道的并行填充与吞吐量提升。

向量通道并行处理
08ROOFLINE MODEL

Roofline 模型

算术强度（FLOPs/Byte）与可达性能（FLOP/s）的 Roofline 曲线可视化。调节峰值算力与内存带宽，观察计算密集型与访存密集型内核的瓶颈转折点。

性能屋顶曲线
