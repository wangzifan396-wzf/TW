01 / SHORTEST PATH

最短路径

在带权无向图中寻找单源最短路径。对比 Dijkstra（贪心 + 优先队列）与 Bellman-Ford（动态规划松弛）两种经典算法的执行过程与效率差异。

算法说明

Dijkstra 每轮从未访问节点中选取距离最小者，松弛其邻边，适合非负权图，复杂度 O((V+E)logV)。Bellman-Ford 对所有边重复松弛 V−1 轮，可处理负权并检测负环，复杂度 O(VE)。本可视化以帧记录访问与松弛事件，高亮最终最短路径。

02 / MINIMUM SPANNING TREE

最小生成树

在带权连通无向图中选取权值最小的边集合，使所有节点连通且无环。对比 Kruskal（按边权排序 + 并查集）与 Prim（从一点扩张）两种贪心策略。

最小生成树可视化 weighted · undirected
树边
考察中
成环舍弃
480
算法说明

Kruskal 将所有边按权值升序排列，依次尝试加入；用并查集判断是否成环，不成环则纳入 MST。Prim 从起点出发，每轮选取连接树内与树外且权值最小的边扩张。两者均得最小生成树，复杂度分别约 O(ElogE) 与 O(ElogV)。

03 / MAX FLOW

网络流

在有向容量网络中求源点到汇点的最大流。Ford-Fulkerson 方法以 BFS 寻找增广路径（Edmonds-Karp），沿路径推进流量并维护残留网络，直至无增广路径。

最大流可视化 directed · capacitated
增广路径
饱和边
未用容量
700
算法说明

Ford-Fulkerson 反复寻找 s→t 的增广路径，沿路径推进其瓶颈容量，并在残留网络中加入反向边以允许「撤销」。当无增广路径时累计流量即最大流。Edmonds-Karp 用 BFS 选最短增广路径，复杂度 O(VE²)。边上标注「flow/cap」，残留以虚线表示。

04 / GRAPH COLORING

图着色

为图中相邻节点分配不同颜色。对比贪心着色（快速但不一定最优）与回溯着色（在限定颜色数下精确求解，含冲突检测与回退）。

算法说明

贪心 按节点顺序，为每个节点选未被邻居占用的最小颜色号，速度快但用色数可能非最优。回溯 在给定颜色数下逐节点尝试每种颜色，遇冲突回退，可判定 k-可着色性。着色数即所需最少的颜色数（色数 χ(G)）。

05 / STRONGLY CONNECTED COMPONENTS

强连通分量

在有向图中寻找极大强连通子图（分量内任意两点互达）。Tarjan 算法以一次 DFS 配合索引与 low-link 值，在栈上识别并输出每个 SCC。

算法说明

Tarjan 为每个节点维护发现序 index 与可达最早祖先 low。DFS 时将节点入栈；当 low==index 时弹出栈顶直至当前节点，构成一个 SCC。每个 SCC 以独立颜色高亮分组。复杂度 O(V+E)。

06 / BIPARTITE MATCHING

匹配算法

在二分图中寻找最大匹配。匈牙利算法（Kuhn）以增广路径为核心：对每个左侧节点尝试寻找可增广的右侧匹配，沿交替路径翻转以扩大匹配规模。

匈牙利算法可视化 bipartite · augmenting path
匹配边
增广搜索
未匹配
520
算法说明

匈牙利算法（Kuhn 实现）遍历每个左侧顶点，用 DFS 寻找增广路径：从一条未匹配边出发，经匹配边、未匹配边交替延伸；若到达未匹配右侧顶点则增广成功，翻转路径上的匹配状态使匹配数 +1。当所有左侧顶点处理完毕即得最大匹配。

07 / TOPOLOGICAL SORT

拓扑排序

对有向无环图（DAG）线性排序，使每条有向边 u→v 中 u 排在 v 之前。对比 Kahn 算法（入度队列）与基于 DFS 后序逆序的两种实现。

算法说明

Kahn 维护入度表，反复取出入度为 0 的节点并入序列，删除其出边并更新后继入度；若最终序列长度小于节点数则存在环。DFS 方法对图做深度优先遍历，节点完成时入栈，最终栈顶到栈底即一个合法拓扑序。两者复杂度均 O(V+E)。
