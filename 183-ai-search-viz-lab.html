AI搜索与信息检索可视化实验室

从 Perplexity 到多跳推理搜索——把 2026 年 AI 如何重塑搜索引擎的核心机制以可交互 SVG 呈现。

01

AI 原生搜索架构

Perplexity 模式搜索全流程：用户查询 → 查询理解 → 并行多源检索 → 结果聚合 → LLM 生成答案 → 引用标注。点击执行完整管线动画。

02

查询理解与改写

查询意图识别、查询扩展、查询分解：原始查询 → 意图分类 → 子查询生成 → 查询扩展。点击查看具体改写案例。

03

多跳推理搜索

复杂问题的多步检索：第1跳检索 → 提取线索 → 第2跳检索 → ... → 综合答案。点击执行多跳推理链。

04

RAG 增强搜索

RAG 在搜索中的应用：查询 → 向量检索 → 语义重排 → 上下文组装 → LLM 生成 → 引用验证。点击执行 RAG 管线。

05

实时索引与增量更新

搜索引擎实时索引机制：网页爬取 → 增量索引 → 向量索引更新 → 时效性排序。点击触发一次索引更新管线。

06

多模态搜索

文本/图像/视频/音频统一检索：跨模态编码 → 共享嵌入空间 → 多模态匹配。点击切换模态查看向量分布。

07

AI 重排序策略

搜索结果 AI 重排序：初检结果 → LLM 打分 → 上下文相关性 → 用户意图匹配 → 最终排序。点击观察重排动画。

08
