MODULE 03

Perlin Noise 柏林噪声

梯度噪声插值生成平滑连续的伪随机场，是地形、云雾、纹理的基础。1D 作地形剖面，2D 作高度图，3D 作体素切片。FBM 叠加多倍频。

2D Perlin Noise

MODULE 04

Reaction-Diffusion 图灵斑图

Gray-Scott 模型：两种反应物 U/V 扩散并反应，参数 F（feed）与 k（kill）决定斑点、条纹、孔洞等图灵斑图。播放观察自发对称破缺。

reaction-diffusion.svg
U 高（基底） 过渡 V 高（反应物） 活跃边界

Gray-Scott 方程

∂U/∂t = Du·∇²U − U·V² + F·(1−U) ∂V/∂t = Dv·∇²V + U·V² − (F+k)·V

Du=1.0, Dv=0.5（相对）。U 像底物，V 像催化剂。F/k 落入特定区间时，V 自组织成稳定斑点或条纹——即图灵斑图。

MODULE 05

粒子系统与流场

粒子在向量场中运动：Perlin 流场平滑漂流、引力中心吸引/排斥、湍流随机扰动。轨迹叠加形成丝绸般流动线条。

MODULE 08

Voronoi 与 Delaunay

Voronoi 把平面按最近邻分区；Delaunay 三角剖分最大化最小角，二者互为对偶。点击添加点，重新生成观察结构演化。

Voronoi + Delaunay
