吴恩达开源的多模型 LLM 统一调用 SDK
aisuite 提供统一的 Python 接口，让开发者以一致的 API 调用 OpenAI、Anthropic、Google、Groq、Mistral、Ollama 等 20+ 大语言模型提供商。核心理念是切换 LLM 提供商只需修改一行代码，业务逻辑无需改动，从而实现模型层的彻底解耦与可替换，降低供应商锁定风险。
