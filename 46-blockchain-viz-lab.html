区块链可视化实验室

通过 8 个交互式可视化模块，从区块结构到跨链桥，逐层拆解区块链系统的核心原理。每个模块均包含 SVG 可视化、实时动画与可调参数，零外部依赖，单文件运行。

8 Modules SVG + Vanilla JS Zero Dependencies Single File
01BLOCK STRUCTURE

区块链结构

区块由区块头（前向哈希、默克尔根、时间戳、随机数、难度）与交易列表组成，区块之间通过哈希指针链接成链。篡改任意数据都会改变哈希并破坏链的完整性。

区块链示意
02CONSENSUS

PoW / PoS / DPoS 共识

共识机制决定谁有权生产区块：工作量证明靠算力竞争，权益证明按持币量加权抽选，委托权益证明由投票产生的代表轮流出块。三者安全性、能耗与最终性各不相同。

共识过程
03MERKLE TREE

默克尔树

默克尔树将交易两两哈希、自底向上归并出唯一的默克尔根。它能在 O(log n) 时间内验证某笔交易是否包含在区块中，是轻节点与 SPV 的基础。

默克尔树构造与证明
04EVM

智能合约 EVM

以太坊虚拟机以栈式架构执行字节码：取指、译码、执行，每条操作码消耗 gas。本模块逐指令演示栈的压入弹出、内存与存储读写以及 gas 扣减过程。

EVM 执行可视化
05TX LIFECYCLE

交易生命周期

一笔交易从用户发起，经钱包签名、广播进入内存池、被矿工打包进区块，再到随区块确认深度增加而最终确认。每个阶段都有对应的状态与风险。

交易流转
06LIGHTNING · L2

闪电网络与 Layer 2

闪电网络通过双向支付通道把大量交易移到链下，用 HTLC 实现多跳路由，最终只在主链开启与关闭通道。它极大提升了吞吐并降低了手续费。

支付通道与路由
07DEFI

DeFi 协议

去中心化金融的核心原语：自动做市商（AMM）以恒定乘积 x·y=k 定价，借贷协议按利用率动态调整利率。本模块演示兑换对储备与价格曲线的影响。

AMM / 借贷 / 流动性
08CROSS-CHAIN BRIDGE

跨链桥

跨链桥连接异构区块链：锁铸模型在源链锁定、在目标链铸造；销铸模型销毁源链资产再铸造；流动性模型靠资金池两端兑换。消息需经中继与确认才能到达对端。
