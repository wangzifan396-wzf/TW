用 Rust 核心 + TypeScript 前端重新定义开源视频编辑器，隐私优先，完全免费
OpenCut 是开源的剪映/CapCut 替代品，采用 Rust 核心重写搭配 TypeScript 前端，支持桌面端和移动端。规划功能包括 Editor API、第三方插件系统、MCP Server 和 Headless 自动化能力，致力于构建隐私优先的开源视频生态，让创作者完全掌控自己的数据。
