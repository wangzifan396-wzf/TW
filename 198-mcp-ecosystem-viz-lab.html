MCP 协议生态可视化实验室

从工具连接到生态爆发——把 2026 年 Model Context Protocol 如何标准化 AI 与外部工具连接的核心机制以可交互 SVG 呈现。

01

MCP 三角色架构全景

MCP 协议核心三角色：Host(LLM 应用) → Client(协议适配) → Server(工具/资源/提示)。点击按钮模拟完整通信流程。

02

Tools 工具调用机制

MCP Tools 完整调用链：工具定义(JSON Schema) → LLM 调用 → 参数验证 → 执行 → 结果返回。点击按钮执行一次工具调用序列图。

03

Resources 资源机制

MCP Resources：资源 URI → 内容读取 → 上下文注入 → LLM 理解。不同资源类型有不同的访问方式。点击按钮模拟资源读取流程。

04

Prompts 提示模板机制

MCP Prompts 参数化模板：模板定义 → 参数填充 → 消息组装 → 发送 LLM。点击按钮组装一条提示消息。

05

传输层协议对比

MCP 三种传输协议：stdio(本地进程) vs SSE(远程流式) vs WebSocket(双向通信)。点击按钮切换传输模式，观察适用场景变化。

06

MCP Server 生态地图

MCP Server 生态分类：文件系统/数据库/Git/Slack/浏览器/搜索/API 等。点击按钮切换类别，查看每个类别的热门 Server。

07

安全与权限模型

MCP 多层安全：用户授权 → 工具权限 → 沙箱执行 → 审计日志。点击按钮切换安全层，查看每层的防护机制。

08

MCP vs Function Calling

MCP 与传统 Function Calling 的核心差异：标准化程度/动态发现/双向通信/资源管理。点击按钮切换对比维度。
