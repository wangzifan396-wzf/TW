MODULE 01

Fitts 定律 · 运动时间模型

Paul Fitts 于 1954 年提出：指向一个目标所需时间与目标距离成正比，与目标宽度成反比。调节距离 D 与宽度 W，点击目标实测运动时间。

fitts-law.svg
起点 / 目标 运动轨迹 实测样本 预测曲线

Fitts 定律（Shannon 公式）

MT = a + b · log₂(D / W + 1)　　ID = log₂(D / W + 1)

调节滑块改变目标距离 D 与宽度 W，观察难度指数 ID 的变化。点击“开始测试”后，从左侧起点快速移到右侧目标并点击，记录实测运动时间。

MODULE 02

Hick 定律 · 决策时间模型

William Hick 提出：从 n 个选项中选择一个的时间随选项数对数增长。改变选项数量，点击高亮目标，实测反应时间。

hick-law.svg
选项 目标选项 实测 RT 预测曲线

Hick 定律

RT = a + b · log₂(n + 1)

调节选项数量 n，点击“开始测试”后等待目标高亮，尽快点击它。反应时间随 n 对数增长，但增长速率远慢于线性。

MODULE 04

认知负荷理论

John Sweller 提出：工作记忆容量有限。认知负荷分为内在、外在、相关三类。切换场景（专家/新手、好设计/差设计）观察负荷分布变化。

cognitive-load.svg
内在负荷 (Intrinsic) 外在负荷 (Extraneous) 相关负荷 (Germane)

场景说明

内在负荷由任务本身难度决定；外在负荷由糟糕设计产生，应尽量消除；相关负荷用于建构图式，是有益的。总负荷不应超过工作记忆容量（约 7±2 项）。

MODULE 06

信息架构 · 导航层次

网站/应用的信息组织结构：广度优先（浅而宽）vs 深度优先（窄而深）。点击节点展开/折叠，切换结构类型观察点击成本。

information-architecture.svg
根节点 分类 叶子页面

Miller 定律与层次设计

人类短时记忆约 7±2 项。每层 5-9 个选项最易扫描。过宽则每层决策慢，过深则路径长。Hick 定律决定了每层的选择时间，层次深度决定总路径时间。

MODULE 07

反馈延迟与 Doherty 阈值

IBM Doherty 发现：系统响应低于 400ms 时用户保持“流畅”心流。调节延迟，点击按钮体验不同延迟下的感知差异。

response-latency.svg
即时 (<100ms) 流畅 (<400ms) 中断 (400-1s) 断连 (>1s)

Doherty 阈值

响应在 100ms 内感觉“即时”；400ms 内感觉“跟手”；超过 400ms 用户注意力开始分散；超过 1s 需明确加载指示；超过 10s 用户可能离开。

多模态交互

语音、手势、眼动、触控四种模态各有特性。切换模态查看其带宽、延迟、适用场景，以及多模态融合策略。

multimodal.svg

模态特性

多模态融合（Oviatt 提出）分三个层次：信号级、特征级、决策级。互补模态可提升鲁棒性，例如语音+手势在噪声环境下互相补偿。WIMP 界面正让位于自然交互。
