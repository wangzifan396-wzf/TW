核心概念速查 · 8 个关键词理解代码知识图谱与 MCP 协议生态

tree-sitter
支持 158 语言的增量解析框架，生成容错 AST，编辑后只重算受影响子树。
AST
抽象语法树：源码的结构化表示，每个节点对应一个语法构造并带位置信息。
知识图谱
函数/类/模块/路由为节点，调用/引用/依赖为边的可查询图结构。
MCP
Model Context Protocol：标准化 LLM 与外部工具连接的 JSON-RPC 协议。
Token 节省
图谱结构化查询只取相关子图，上下文 token 从 9.2 万降至 920，节省 99%。
调用链
函数间调用关系形成的路径，支持 N 跳遍历与影响面分析。
持久化
图谱落盘存储到 .kg 目录，重启不丢失，单 C 二进制零依赖。
增量更新
文件改动后 diff 新旧 AST，仅对变化部分重解析并合并入图谱。
