现代终端文件管理器 · Go编写 · 双面板界面 · 插件主题系统 · Vim快捷键 · 跨平台支持
Superfile 是用 Go 编写的现代终端文件管理器，界面美观且功能丰富。支持 Linux、macOS 和 Windows 三大平台，提供插件与主题系统，支持自定义快捷键（包括 Vim 用户专用配置），具备自动更新检查功能，是终端用户的现代化文件管理利器。
