本地优先代码智能图谱 · Tree-sitter AST解析 · 爆炸半径分析 · MCP/CLI集成
Code Review Graph 是面向 MCP 和 CLI 的本地优先代码智能图谱工具。利用 Tree-sitter 解析代码库生成 AST 图谱，计算变更影响范围（爆炸半径），大幅减少 AI 上下文 Token 消耗。支持数十种编程语言，可配置多种 AI 编码工具 MCP，集成 GitHub Action 实现自动化代码审查，让 AI 理解整个代码库的结构与依赖关系。
