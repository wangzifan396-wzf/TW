CORE CONCEPTS · 核心概念速览
AST
抽象语法树，源码经词法/语法分析后的结构化树形表示
BPE
Byte-Pair Encoding，子词分词算法，将代码切为可复用子词单元
FIM
Fill-In-the-Middle，训练范式，让模型学会在上下文中间填空
Beam Search
解码策略，每步保留 top-k 候选并行展开，平衡质量与多样性
RAG
检索增强生成，先检索相关代码片段再拼入 prompt 供 LLM 生成
DSL
领域特定语言，程序合成中受限的算子集合，定义搜索空间
pass@k
代码生成评估指标，每题采样 k 次至少 1 次通过的比例
KV Cache
推理时缓存的 Key-Value 张量，避免重复计算，支持驱逐策略

04RETRIEVAL-AUGMENTED

RAG for Code
