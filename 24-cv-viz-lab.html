COMPUTER VISION · INTERACTIVE SVG LAB

计算机视觉可视化实验室

通过 8 个交互式 SVG 可视化模块，直观理解计算机视觉核心算法：从卷积运算、残差连接、目标检测，到语义分割、注意力机制与模型评估。纯 HTML/CSS/JS + SVG 实现，零外部依赖，单文件运行。

8 Modules SVG + Vanilla JS Zero Dependencies Single File
01CONVOLUTION OPERATION

CNN 卷积核

可视化卷积核在输入特征图上滑动的过程，展示加权求和如何生成输出特征图。支持不同卷积核类型与步长配置。

卷积运算可视化
02RESIDUAL CONNECTION

ResNet 残差连接

展示 ResNet 残差块结构：输入分为主路径与恒等映射，相加后输出。对比有无跳跃连接时梯度流的差异。

残差块与梯度流
03OBJECT DETECTION

YOLO 目标检测

可视化 YOLO 检测流水线：输入图像经过 Backbone、Neck、Head 输出网格预测与边界框。展示网格单元、锚框与置信度。

检测流水线
04SEMANTIC SEGMENTATION

语义分割 U-Net

可视化 U-Net 编码器-解码器架构：特征图分辨率在编码器中递减、在解码器中递增，跳跃连接桥接对应层级。

U-Net 架构
05NON-MAXIMUM SUPPRESSION

NMS 非极大值抑制

逐步演示 NMS 算法：按置信度排序，保留最高分框，抑制 IoU 超过阈值的重叠框。可调节 IoU 阈值与单步执行。

NMS 算法演示
06VISION TRANSFORMER

ViT 图像分块

可视化 Vision Transformer：图像切分为 Patch，展平嵌入并加入位置编码，送入 Transformer 编码器。展示分块网格与注意力模式。

ViT 分块与嵌入
07DATA AUGMENTATION

数据增强

展示各类数据增强变换：翻转、旋转、裁剪、颜色抖动、MixUp、CutMix。通过强度滑块控制变换程度，对比原图与增强结果。

增强变换可视化
08DETECTION EVALUATION

目标检测评估 AP/mAP

可视化 Precision-Recall 曲线与 AP 计算，展示 IoU 在预测框与真实框之间的计算过程。调节阈值观察评估指标变化。

PR 曲线与 IoU
