MODULE 03

TVM · AutoTVM / Ansor 自动调优

算子在不同硬件上需选择最优 tile 与循环展开参数。AutoTVM 用模板搜索，Ansor 用进化+代价模型自动生成调度。调整 tile 参数观察矩阵分块策略与调优曲线。

tvm-autotuning.svg

tile 参数搜索

MODULE 04

MLIR · 多层中间表示与 Pass 管道

MLIR 通过嵌套 dialect 表示不同抽象层：高层的 toy/linalg → affine → SCF → LLVM IR。每个 Pass 将上层 dialect 下降为下层。点击 Pass 观察逐层 lowering。

mlir-dialects.svg
当前层 已完成 Pass 下降 未处理

Dialect 下降

linalg.generic 表示数据并行计算；affine 将循环结构显式化便于多面体优化；scf 转为结构化控制流；最终 LLVM dialect 直通 LLVM 后端生成机器码。每层保留前层语义并增加低层细节。

MODULE 05

XLA · HLO IR 与 GPU 融合

XLA 将前端算子编译为 HLO IR，再经融合与代码生成产出 GPU kernel。融合策略把 elementwise + reduce 等 producer-consumer 合并以减少显存带宽压力。切换融合级别观察 kernel 数量变化。

xla-hlo-fusion.svg
HLO 算子 融合组 生成 kernel fusion 边界

XLA 融合策略

HLO IR 是显式数据流图。XLA 三种融合：kLoop（同形状 elementwise 链）、kInput（reduce + elementwise）、kOutput（输出分裂）。融合后多个 HLO 编译为单个 GPU kernel，中间张量留在寄存器/共享内存。

MODULE 06

自动微分 · 前向 / 反向模式

前向模式沿计算图传播切线，适合输入少输出多；反向模式（反向传播）先前向求值再反向求梯度，适合输入多输出少（loss 标量）。点击单步观察前向值与梯度在图上的传播。

autodiff.svg
前向值 v 梯度 ∇ 已传播 当前步

反向模式

计算图：z = (x·y) + sin(x)。前向：t₁=x·y=6, t₂=sin(x)≈0.84, z=t₁+t₂≈6.84。反向：∂z/∂t₁=1, ∂z/∂t₂=1；∂z/∂x=∂z/∂t₁·y + ∂z/∂t₂·cos(x)=3+0.34=3.34；∂z/∂y=∂z/∂t₁·x=2。一次反向遍历得到所有输入梯度。

MODULE 07

内存规划 · buffer 分配与复用

编译器为每个中间张量分配 buffer。朴素策略每个张量独立分配导致峰值高；基于活性分析的重叠着色策略让不重叠生命期的 buffer 共享内存。切换策略对比峰值内存。

memory-planning.svg
buffer 生命期 内存槽 (复用) 峰值内存 节省

活性分析与重叠着色

每个 buffer 有 [定义点, 最后使用点] 的生命期区间。若两区间不重叠则可共享同一内存槽（图着色）。朴素分配峰值=Σsize；复用分配峰值=max_t Σ(活跃 size)，通常显著降低。模拟搜索/静态规划会进一步做尺寸对齐与碎片整理。

MODULE 08

算子库 · cuDNN / MKL / TensorCore

编译器后端将算子映射到高度优化的库：cuDNN 处理 Conv，MKL 处理 CPU 线性代数，TensorCore 做 WMMA 矩阵乘。切换算子与输入配置，观察库选择与 kernel 调用路径。

kernel-library.svg
逻辑算子 cuDNN MKL TensorCore

库选择策略

编译器维护算子→库映射表：Conv 在 GPU 走 cuDNN (Winograd/Implicit GEMM)，在 CPU 走 MKL-DNN；MatMul 当形状满足 m,n,k≥16 且对齐时走 TensorCore (WMMA)，否则走 cuBLAS。autotuning 会在多个候选 kernel 间实测择优。
