04

视觉问答推理路径

多步 VQA 推理：问题分析 → 图像区域定位 → 属性提取 → 关系推理 → 答案生成。用流程图与图像区域高亮展示完整推理路径。

05

视觉定位与分割推理

Grounding 推理链：文本描述 → 语义理解 → 图像区域匹配 → 边界框 / 分割掩码生成。动画在图像上逐步绘制 bounding box。

06

多图推理

多图像比较推理：图 A vs 图 B → 差异检测 → 关系判断 → 结论。用并排图像 + 差异高亮 + 推理链展示比较过程。

07

视频时序推理

视频理解推理链：帧序列输入 → 时序特征提取 → 动作识别 → 因果推理 → 事件总结。用时间轴 + 关键帧 + 推理链展示。
